策略为 `vip_s02_bounded_d1_testroom_v1`，完整身份以同目录 `manifest.json`
的 `release_package_id` 为准。候选公式原文、完整源码（含启动脚本）、
真实数学后端、参数和工程证据均在启动及子进程预热时验签。

自然完赛，不主动结束正在进行的房间。使用SSE，不增加弃牌缓发。

待处理名额；原1秒/3秒动作窗口不变。正式接入须新包与相应门禁。
