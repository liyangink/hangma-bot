# 有限成本的启发式基线优化专项

> 2026-09-07；状态：方案冻结，进入评估门禁施工。用户目标：在可控成本内实施高收益启发式优化，交付可靠保底及后续模型对照基线。本计划接替旧迭代计划中尚未执行的有限调参安排；不撤销 V0/V1/V2 冻结和发布约束。

## 1. 决定和完成条件

**先用一个有边界的阶段补齐评估控制，随后按固定候选、固定开发集、一次独立确认连续推进。**不重建模拟器，不先做完整赛事模拟，也不因某个牌谱案例看起来合理就修改默认策略。

本专项有两个独立结果：

- **必须交付的可靠基线**：合法胡优先、未知事实保守排序、独立紧急保底、真实预算门禁、完整审计、确定性重演与冻结产物。即使强度调优失败也要交付；“可靠”限于已覆盖的规则、时限和故障场景，不承诺所有未来输入无故障。
- **争取达到的效果目标**：共同修正规则下，相对可靠对照，每个 8 单局桌赛平均积分至少增加 **10 个底分单位**，且配对积分差的双侧 95% 置信区间下界大于 0。桌赛第一率点估计不下降，其差值 95% 区间下界不低于 −3 个百分点。全体门槛同时通过才称“在声明的本地对手分布下获得实质且统计显著提升”。

10 分是预先选择的工程价值门槛，不是官方要求，也不是从这批结果倒推出来的阈值。指标是完整桌赛积分，不能用单局高分、胡牌次数或离线动作一致率替代。若实际 Rounds 改变，重新冻结实验，不把 8 单局结果无条件折算到另一配置。

结果允许明确分为：①可靠性与效果均通过；②可靠性通过，但效果未达到门槛，保留可靠对照；③必要可靠性未通过，继续修复而不发布。**不保证显著提升，不追加实验直到显著，不把“未显著”写成“已经等效”。**

## 2. 固定对照、规则与任务范围

**可靠对照 B0 固定为 V1，不再让已知的 V0 排序缺陷成为新模型的正式目标。**V1 的合法胡优先、未知事实处理已经实现；它在此前正常模拟轨迹中与 V0 相同，但本轮仍重新验证当前规则与运行行为。V0 保留为历史参照和现有线上默认，B0 的采用不自动改线上配置。

| 项目 | 固定口径 |
| --- | --- |
| 主对照 | `weighted_heuristic_v1` 默认完整权重，记作 B0 |
| 调优起点 | `weighted_heuristic_v2`；所有实验变体继承可靠排序与缺失过牌事实退路 |
| 紧急保底 | 既有 `SafeFallbackPolicy`；在主策略或未来模型启动前准备，不依赖它们成功 |
| 规则 | 冻结当前 `hangma-mvp-v4-youcai-baotou` 及导出修复；同批所有策略共用同一规则指纹 |
| 本地配置 | `Rounds=8`、`BaseScore=1`、`YouCaiBiKao=true`、1/3 秒窗口；逻辑时钟用于效果，真实时钟用于预算 |
| 信息权限 | 策略只读 `DecisionRequest`；完整世界仅经模拟器公开接口推进；不把赛后信息加入线上输入 |
| 明确不做 | 线上搜索、模型训练、主动弃胡、学习型隐藏牌采样、完整赛事晋级估计器、参数自动优化平台 |

规则版本或候选事实语义变更时，正在进行的效果批次作废并计入成本；修复后重新冻结，旧批只留诊断。不能把修正规则前后的样本拼成一个置信区间。

## 3. 评估体系只补必要能力

**现有完整桌赛驱动、同牌山配对、四次换座和根组 Bootstrap 继续复用。**补齐的是执行与判断的约束，而不是另一套麻将环境。

| 必补项 | 交付与验收 |
| --- | --- |
| 实验注册 | 单一机器可读计划，固定候选、数据划分、房规、对手、样本上限、晋级标准与失败分支；生成实际 CLI 配置并核对 |
| 完整性门禁 | 预期 seed × 换座 × 对照/候选必须齐全；重复、漏行、规则/权重指纹不符、运行错误令整批门禁失败，不能靠排除后剩余样本宣布通过 |
| 分层覆盖 | 不同初始庄家身份与对手配置按预定表平衡；同根组内四次换座先平均，始终只算一个统计单位 |
| 冻结与重启 | 保存源码/规则/配置/输入哈希、精确随机种子、运行目录和状态；仅从完整且指纹一致的任务恢复，失败任务不能覆盖旧日志 |
| 可靠性报告 | 非法、超时、自动动作、保底、缺失审计分别计数；故障注入中的预期保底与正常效果实验中的意外保底分开 |
| 有限成本控制 | 开跑前报告预计桌赛数和耗时；累计尝试数包含失败与重跑；到预算停止，不静默扩容 |
| 确认集封存 | 仅允许最终一个已冻结候选进入一次确认；确认后不再改权重并重复使用该集合 |

不把新包装器做成通用框架；优先调用 `offline/evaluate.py` 与现有统计公开入口。新增完整性逻辑必须用缺行、重复、错配置的负例验证。模块/受控契约若确需改变，再同步架构、主技术方案、接口和调用方；本计划不预建新接口。

## 4. 数据划分与评估分布

**旧牌谱用于解释，新牌山用于开发，最终确认数据只使用一次。**所有划分以牌山根组（同一个独立牌山种子及其换座变体）为边界；同一根组的各视角、案例与变体不可跨集合。

| 集合 | 大小 | 用途 |
| --- | ---: | --- |
| 历史诊断集 H | 已有旧 32 根组及 5 个分叉案例 | 回归解释，不再提供独立效果证据 |
| 工程门禁 G | 最多 128 个桌赛 | 当前规则、B0/V0、一致性、配置和恢复检查；不进入开发或确认统计 |
| 开发筛选 D | 32 个新根组 | 比较 5 个固定变体及至多 1 个预声明组合 |
| 候选选择 S | 128 个新根组 | 仅比较 D 晋级的至多 2 个候选，选至多 1 个确认版本；可以查看结果，属于开发数据 |
| 独立确认 T | 256—1024 个新根组，开跑前定 N | 一次性确认；样本量由 S 方差和预声明公式决定，不读取 T 后调整 |

每个根组只分配一种“初始庄家相对待测策略身份”和一种对手配置，8 种组合等量覆盖；根组内保留四种物理座位轮换，每种轮换分别执行 B0 和候选，所以每根组、每候选 **8 个完整桌赛**。这样覆盖四种首庄身份，但不把每根组扩大成四套首庄实验。

两个对手配置等权：P0 为三个固定 V1；P1 为一个 V1、一个默认 V2、一个积极鸣牌 V2（`claim_risk_chi=0, claim_risk_peng=0, gang_bonus=60`），P1 的三种逻辑位置循环平衡，所有版本冻结。现有评估 CLI 尚不装配 `claim_if_legal`，因此直接使用可装配的参数变体，避免为对手池扩大接口。它们是内部打法压力分布，不代表官方对手分布。各初始庄家身份、对手配置都单独报告；主要总体为这 8 个层的等权平均。

分层 Bootstrap（在每个预定层内对根组有放回重采样，再把层均值等权平均）固定 20,000 次、固定随机种子。每个根组内四次换座不独立计数。当前统计模块已有根组重采样，分层汇总需以小规模可核对数据补验。

## 5. 有限调优菜单

**第一轮只比较现有评分机制，不新增复杂特征或重新定义向听。**源码只有一个 `gang_bonus`，作用于全部杠型；通过现有参数置零必须明确叫“全部杠奖励消融”，不能标成“只关闭明杠”。消融实验（`Ablation`，只改变指定评分因素来观察其作用）也不自动成为发布候选。

| 编号 | V2 基础上的唯一改动 | 要检验的机制 |
| --- | --- | --- |
| C0 | 不改参数 | 判断 V2 本身在修正规则和新分布下是否值得保留 |
| C1 | `gang_bonus=0` | 固定杠奖励是否掩盖等待价值；同时检查暗杠/补杠退步 |
| C2 | `gang_bonus=10` | 保留较小奖励能否在等待与补牌之间取得更好取舍 |
| C3 | `shanten_step=75` | 固定向听阶差是否过度压过有效进张；它影响所有动作，不只吃碰 |
| C4 | `claim_risk_chi=20, claim_risk_peng=12` | 调整 V2 比较标尺后，沿用旧鸣牌惩罚是否过低 |
| C5 | 最佳 C1/C2 的杠奖励 + 最佳 C3/C4 的那组改动 | 仅在两组各至少一个变体在 D 优于 C0 时生成；不再创建其他组合 |

其余权重全部保持默认，每个变体输出有效完整权重。C1/C2 优先基于已有杠案例；C3/C4覆盖更高频的吃碰和弃牌，避免把全部成本花在少见明杠上。此前“只关闭明杠”留为后续条件算法假设，本轮不为它立即新增参数接口。

D 按总体平均积分差降序，第一率差作为同分次序，最后按候选编号确定；仅通过正常运行门禁且两个对手配置的积分差均非负的候选进入前 2。若没有候选总体积分差大于 0，停止本轮强度调优，不进入 S/T。

S 按相同排序选一个候选。进入 T 必须：总体平均积分差 ≥10、第一率差点估计 ≥0、两个对手配置积分差均非负、所有可靠性门禁通过。没有满足者即结束有限搜索，交付 B0；不能从未显著的局部现象临时加第七组参数。

若有限菜单无效，记录下一次研发应优先研究的“有财规则下合法胡进张／成胡路线”事实缺口，但**它是另一份需重新设定成本和数据的算法任务**。本轮不自动滑入规则感知向听、大规模自博弈或在线搜索。

## 6. 样本量、显著性与计算上限

**开发阶段的最好分数不用于宣布提升；只看独立确认 T 的一次结果。**T 前候选与完整权重再次冻结。各 D/S 实验用于选候选，不发布它们的显著性结论；因此不会把 6 次挑选当成 6 次独立确认。T 后换版本需要新计划、新数据和新的多重检验安排。

样本量从 S 中最终候选的根组积分差标准差 s 规划，保守乘 1.25：`N_score = ceil(((1.96 + 0.842) × 1.25 × s / 10)²)`；向上取 32 的倍数，至少 256。另根据第一率差标准差计算在真实差为 0 时排除 −3 个百分点的同类规划量，分母为 0.03。取两者最大，若超过 1024，则标明当前预算不足以按计划验证全部门槛，不截断样本量后声称已满足功效。

该正态近似约对应单个统计检验 80% 功效，不保证包含“点估计 ≥10”和“第一率点估计 ≥0”的整个联合门槛有 80% 通过概率；真实改善恰好等于点估计门槛时，通过该点估计条件的概率可能仅约一半。麻将分差长尾，最终报告使用根组分布与 Bootstrap，功效数值只作预算量级并进行 S 分布重采样敏感性检查。[NIST 样本量方法](https://www.itl.nist.gov/div898/handbook/prc/section2/prc222.htm)、[配对差分析](https://www.itl.nist.gov/div898/handbook/prc/section3/prc311.htm)（2026-09-07 查阅）。

第一率门槛验证所需成本可能高于平均积分。若超预算，交付“积分候选／排名风险未确认”，而不弱化 −3 个百分点界限。可以报告已完成开发结果，但不称为总体效果通过，也不临时改成更易显著的指标。

| 批次 | 最多桌赛数（保守计入重复 B0） |
| --- | ---: |
| G 工程检查 | 128 |
| D：6 ×32 根组 ×8 | 1,536 |
| S：2 ×128 根组 ×8 | 2,048 |
| T：1 ×1024 根组 ×8 | 8,192 |
| 合计正常上限 | 11,904 |
| 含失败重试的硬上限 | **12,288** |

默认最多 2 个离线工作进程，不影响正在运行的官方任务；总离线工作进程占用不超过 **96 进程小时**，按每个进程实际运行墙上时间相加。桌赛数与时间任一到上限即停止提交新任务，在当前桌赛边界收尾，不通过增加机器或购买资源绕开上限。

旧批每桌约 20—25 秒只提供量级：正常最大批量约 66—83 个顺序工作小时；新规则、复杂候选和并行竞争会改变速度。G 记录真实吞吐，T 开跑前用剩余预算核算整批可完成性，不能先跑一半再临时追加资源。早期无效会直接跳过大样本确认，实际成本通常低于上限；这里没有承诺完成日期。

## 7. 测试与可靠性门禁

**策略效果和运行可靠性分别验收，逻辑时钟的零超时不能充当真实时限证明。**

1. 当前规则/模拟回归：有财必拷响官方金例、已知向听反例、四庄家导出再导入、跨单局结算、完整桌赛终态。
2. 策略行为与故障：胡优先、可信/未知排序、已拒过滤、重复去除、紧急动作保留；异常、超时、空计划、缺失事实均可进入合法保底；记录保底原因与审计链。
3. 真实预算：冷/热启动、1 秒响应和 3 秒出牌、目标 M 下同一事件循环并发，从紧急动作准备到最终复核计时，复用生产截止时间。已有断言全部保持，不放宽预算换取通过；重点检查新增变体的最慢输入。
4. 效果批次：全部完整桌赛、所有配对齐全、正常输入下零非法/超时/意外保底/审计缺失。失败留档并定位，不能靠排除后继续宣称通过。
5. 发布边界：本专项交付可复现本地基线与验收报告；实际替换线上默认还需同版本官方测试房、测试赛事和人工发布审核。已有其他版本的线上证据不自动覆盖新候选。本轮不擅自启动外部赛事，也不把平台可用性变成离线工作的等待点。

## 8. 交付给模型训练的基线包

**后续模型必须对同一个可重建基线做比较，而不是对一个会移动的分支。**产物含精确提交及源码差异、规则指纹、完整权重、装配名称、依赖环境、时钟模式、对手池、分层/种子清单、原始桌赛结果、审计摘要、测试日志和最终门禁判断。

交付 `reliable_baseline` 预设指向最终通过可靠性门禁的 B0 或候选；`emergency_fallback` 仍指既有独立紧急保底。只增加必要的固定配置/装配，不创建模型注册表。二者用途不同：模型超时回到启发式，启发式失败仍有紧急动作。

D/S及历史牌谱可进入后续模型开发数据，并标明其已被启发式调参使用；T 使用后变成“已消费确认集”，不得继续充当后续模型的独立留出集。该包用于公平对照和数据追溯，不把策略自身动作当作最优标签，也不把固定他家暗牌的牌墙扰动当作无偏教师。

## 9. 连续推进与阶段结果

**一次授权后按本表执行，不在每个参数试验结束时停下来重新规划。**节点间条件已经声明，进度更新只报告结论、预算和下一门禁；无需逐项再询问是否继续。

| 阶段 | 工作 | 通过后 | 不通过后 |
| --- | --- | --- | --- |
| P0 | 计划/配置生成、冻结、完整性负例、相关回归及 G | 自动进入 D | 修复必要控制；超过实现/运行预算就交付阻碍与可靠基线现状 |
| P1 | C0—C4 全量 D，按条件加 C5 | 自动选至多 2 个进入 S | 停止效果菜单，转 P4 固化 B0 |
| P2 | S + 最终候选真实预算 + 功效/成本核算 | 冻结一个候选与 T 样本量，自动进入 T | 转 P4；明确无收益或证据成本过高 |
| P3 | 一次完整 T，固定指标判门禁 | 转 P4 固化通过候选 | 转 P4 固化 B0，封存失败候选；不重开 T |
| P4 | 固定基线包、重演命令、测试及研究结论 | 本专项本地交付完成 | 必要可靠性问题仍未解决时不能标完成 |

评估控制施工目标不超过 1 个工作日量级，候选全部利用现有权重配置；若发现需要跨模块大改才能实现菜单，优先删除非必要实现需求，不能无限扩大本专项。成本账本与下一步状态统一保存在 `review/heuristic-baseline-campaign-2026-09-07/`。

## 10. 依据与已改变的判断

本轮[续打专项](../../review/policy-followup-study-2026-09-07/README.md)已完成 198 条单局分支：4 个续打偏差不改变 V2 首选；03 明杠在固定暗牌、16 次牌墙扰动下相对过平均 −29；其他吃碰方向不稳定。这只确定待测机制，不能提供效果晋级证据。

[现有评估接口](./evaluation-start.md)已经明确同牌山换座、根组聚类和数据隔离；本计划补齐执行层的硬门槛。[旧迭代计划](./policy-iteration-plan.md)的 V3 六组参数不再作为另一批并行搜索重复执行。完整赛事晋级估计仍是后续能力；当前目标是可靠的启发式基线，不用它拖延有限成本的本地优化。
