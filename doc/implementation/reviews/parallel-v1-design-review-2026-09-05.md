## 1. 审查结论

本次按规范/需求两轴独立审查。一个新的接口语义冲突已修正并复核；没有剩余的实施阻塞发现。这不表示新模块已经实现或性能、强度门禁已经通过。

| 项目 | 发现及本次处理 | 实施时仍须验证 |
| --- | --- | --- |
| 旧 S1 | codec 在 emit 前失败可能只留内存标记；[审计 §3.4](../audit-enhancement.md#34-故障持久化与发送截止时间)明确最小失败记录、producer_summary 与关闭报告合并 | codec 抛错而 sink 正常时，迁移后报告必须不完整且可定位 |
| 旧 S2 | 发送前审计可能跨过最后 deadline；同节要求同步审计后最终检查，超时 SubmitNotSent | 假时钟跨界，HTTP 动作调用数为 0 |
| 旧 R1 | 本地阶段尝试 UUID 无法四视角合并；[共同契约 §4](../parallel-contracts.md#4-数据身份来源及版本)定义稳定 hand_id/index/split_group_id | 四进程加一次重启合为一个单局、五份 view，同一划分组 |
| 新 P1 | 自动匹配 initialize 入席与原初始化只读约束冲突，重试所有权重复 | 已在[接口协议 §6](../interface-contracts.md#6-赛事与参赛者终态)、[共同契约 §3.3](../parallel-contracts.md#33-本次批准的增量扩展)和[自由赛 §2](../free-match-start.md#2-最小实现与接缝)集中登记；实施时同步类型注释、Fake 和模式测试 |

自动匹配 P1 的最终口径：只有显式 AUTO_MATCH、目标为空且排除已有归属才允许初始化入席；非空目标只恢复。application 开始一次操作，adapter 只在该操作内有界恢复；分类终态后不盲目再次 initialize。finished/closed/void 仍由 application 判断。规范轴复核确认已解决。

需求轴核对了现有 TournamentConfig、WindowKey、策略时钟注入和 BudgetPolicy.build：模拟/评估能复用实际类型；WorldState 不透明、同期观察不泄漏、历史核对与世界导入分开、完整桌赛按同牌山组统计均一致。评估可先做固定请求和测试 Fake，无须等待全部模拟能力；Fake 不输出强度结论。
