# 大牌路线评估与策略迭代计划

目标是提高完整桌赛的期望净分：在速度和风险代价合理时保留高价值路线，而非提高最大番数纪录。研究在 `codex/big-hand-paths` 独立工作树进行，起点为 `effc14cf`；不修改主线运行配置和稳定默认。

## 1. 基线与证据边界

分别比较冻结 V2 和已提供自由赛实验的 `v2_hu_upgrade_v1`。先验证单项改动，再验证与等胡组合的增量，避免混淆来源。根据用户 2026-09-09 补充的赛事方说明，正式赛不开启有财必拷，后续研究固定 `YouCaiBiKao=false`；不为开启配置扩充专项优化和验证。已有生产规则配置支持保留。

- 可达性证据：合法动作和指定后续进张能够成牌，只证明可能，不能当成概率或期望净分。
- 条件优势：明确抽样与风险假设后，比较全部支持进张及其结算；同进张数量不代表进张集合相同，也不自动构成支配。
- 效果证据：同牌山、换座位、完整桌赛比较。构造案例通过不等于赛事表现提高。
- 两次摸牌后未成胡记零的旧模型截断了后续价值；保留作短期诊断，不据此否定较远的大牌路线。
- 官方计算器能对不可能发生的链参数给出分数。计番金例与有合法前缀的可达牌局分别记录，不能把七对叠加实际副露杠、超过物理上限的杠数等直接列成策略目标。

## 2. 有序交付

| 阶段 | 产物 | 完成条件 |
| --- | --- | --- |
| A 案例体系 | 版本化案例目录、来源、当前观察、目标动作/进张、反例、覆盖表 | 常见牌型均有合法终点锚；策略案例明确距离、墙余量、正式赛配置、庄闲、动作族；不以非法前缀冒充场景 |
| B 基线诊断 | V2/等胡逐案选择、丢失的路径、代价与原因 | 区分明确浪费、价值速度权衡、信息不足；未来进张不进入策略输入 |
| C 单项优化 | 独立候选、必要事实与审计、回归 | 不改冻结 V2；保留保底和降级；先修复有证据的排序缺陷，再扩展多步价值 |
| D 效果检验 | 预登记开发/独立确认集、完整桌赛和置信区间 | 每组 8 单局、4 座位轮换；按牌山根组统计；对 V2 与等胡分别比较，并验证多种对手 |
| E 发布判断 | 门禁报告、可用枚举和使用范围 | 规则、时限、C/Python 一致性通过；人工审核后才发布或更改默认 |

A/B 先覆盖平胡/七对/豪华七对、爆头、财飘/连续飘、四白、杠开/合法连杠与可达组合。距离覆盖已听、距听一至三步；墙余量覆盖长、中、短。不是机械生成全部笛卡尔积：每一格须有物理有效且有辨别力的案例。不能构造的组合明确排除及说明原因。

案例必须包含保留对子、保留白板、吃碰开门、杠的机会成本、放弃眼前小胡等动作，以及以下负例：关键进张耗尽、墙短、明显速度损失、无白、未知公开计数。弃掉某张牌仅表示指定路线受损；除开门排除七对等明确情况外，不声称该牌型永久不可达。

多步评估需要覆盖截断时的剩余价值、他家先胡风险与续打策略敏感性。固定未来序列只用作离线教师证据；首次选择不能偷看随后进张。完整世界只能经模拟器公开接口使用，牌型算法统一调用 `hangma`。

## 3. 预登记门槛与停止条件

沿用稳定版替换门槛：每桌赛平均净分增量至少 10，95% 置信区间下界大于 0；严格第一名比例点估计不下降、区间下界不低于 -3 个百分点；规则与运行可靠性通过。未达到不包装成稳定优秀版本，也不自动换默认。实验版可以单独记录其明确收益与限制。

开发集与确认集不混用。旧研究已经使用的 970000—1040127 段及预留段不作为新确认数据；新实验执行前登记种子范围、策略哈希、续打/对手/规则版本、停止规则。调参后须使用新的确认集。

常规实现、测试、修复与失败后重新设计自行推进。出现目标定义冲突、必须依赖拿不到的外部信息、或独立证据持续否定当前方向时才请求方向讨论。零触发首先检查覆盖与机制；阴性结果先检查模型截断和样本量，不直接认定大牌路线没有价值。
