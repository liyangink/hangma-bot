# 候选积分标签：原始资料与训练边界

核查日期：2026-09-11。用途：指导离线标签试验；不修改线上契约，不作为杭麻规则依据，也不宣称这种方法已在杭麻提高桌赛积分。

## 结论

**工程建议：可以开始，不必先建完整隐藏世界后验采样器。**从自然模拟轨迹保存完整世界状态（`WorldState`，模拟器拥有的四家手牌、牌墙和规则状态），在同一决策边界固定 2—4 个合法候选，分别应用首动作并续打至本局结束，保存四家积分变化。所有续打策略仍只能读取各自玩家观察（`PlayerObservation`，当时依法可见的信息）。

这些是候选结果模型（`CandidateOutcomeModel`，观察加动作到本局四家联合积分结果分布）的**样本标签**；单个世界的结果不是该观察下的期望积分，更不是最优动作金例。训练模型只读观察和候选，可通过不同自然世界的样本学习条件均值或分布；能否学准及改善完整桌赛，必须另行验证。

这也澄清[此前文献笔记](heuristic-methods-literature-2026-09-10.md)“按实际完整世界续打只可作为事后诊断”的适用范围：不能直接将单牌山结果当作线上可知答案；**并不禁止将其作为合法观察模型的一条离线积分样本。**

## 推导：一个自然世界为何可以作为标签

**以下是对本项目采样方案的数学推论，不是上述论文对杭麻作出的结论。**

记 `D` 为冻结的发牌、历史行为策略、对手池和决策窗口采样规则共同产生的分布；`O=o` 为模型实际使用的玩家观察。先固定合法首动作 `a`，随后四个座位按冻结续打策略组 `π` 行动。记：

\[
G_a^\pi=(\Delta S_0,\Delta S_1,\Delta S_2,\Delta S_3),\qquad
Q_{D,\pi}(o,a)=\mathbb E_D[G_a^\pi\mid O=o].
\]

积分单位是规则结算的桌内积分；向量固定按物理座位 0、1、2、3，`ΔS` 从分叉前算到本局结束，不包含后续单局。动作是**主动应用的候选首动作**，不是按历史上“实际选择了 a”再筛选样本。

若自然世界 `W` 从 `D` 产生，窗口与候选选择只依赖 `O` 和独立随机数，则保留下来的世界在给定 `O=o` 时仍服从对应的条件分布。由条件期望的迭代公式：

\[
\mathbb E[G_a^\pi\mid O=o]
=\mathbb E_{W\mid O=o}\!\left[\mathbb E[G_a^\pi\mid W,O=o]\right].
\]

所以每个自然世界的一次正确续打结果，是这个目标的一次随机样本。这里没有要求显式计算 `P(W|O)`；但要求不按后续输赢、番数、分叉积分、隐藏手牌或未来单局长度挑窗口、删失败样本。特别是单局结束后从全部窗口等概率抽一个，会使某个窗口的入样概率依赖未来总窗口数，不能不记录或校正就声称代表原始部署分布。若筛选依赖模型输入之外的历史，也要把筛选条件显式记录，不能仍声称对应原来的 `D`。

以我方座位 `i` 的均值预测 `f(o,a)` 为例，平方误差满足：

\[
\mathbb E[(G_{a,i}^\pi-f(o,a))^2\mid O=o]
=\operatorname{Var}(G_{a,i}^\pi\mid O=o)
 +(Q_{D,\pi,i}(o,a)-f(o,a))^2.
\]

因此，无限制函数在总体平方误差下的最优解是条件均值。**这不证明实际小网络已学到它**：观察往往不重复，泛化依赖特征、样本覆盖和模型能力；有限样本训练还会有拟合误差。如果当前观察编码未保留完整决策历史，这个条件均值依然有定义，但不能直接套用完整马尔可夫状态下的策略改进保证。

分布标签同理可以保留原始四家联合积分样本后建模。只训练四个均值，不能据此声称已经得到联合分布；四个边际分布也不能直接当相互独立来计算名次。

## 必须避开的两种误用

**先逐世界选赢家，再监督动作分类，会改变优化目标。**分类器可能学到“哪个动作最常在事后成为赢家”，而不是哪个动作有最高期望积分。下面是说明此差异的自造例子，不是杭麻实测：

| 隐藏世界概率 | 动作 A 的我方积分 | 动作 B 的我方积分 |
| --- | ---: | ---: |
| 90% | +1 | 0 |
| 10% | −100 | 0 |

A 在 90% 世界中胜出，但平均积分为 `−9.1`，B 为 `0`。更一般地，`E[max_a G_a | O] ≥ max_a E[G_a | O]`；前者使用事后信息，不能当观察策略可达到的基准。应保留每个候选的原始积分，先估计观察条件结果，再按声明的赛事目标选择。

**全知续打的偏差与单世界样本噪声是两回事。**若在后续每一步用隐藏牌墙替策略选动作，即便最终学生只读观察，标签仍评价了不可执行的全知续打。若每个座位全程只读自己的观察、合法记忆和独立策略随机数，就避免了这种特定的全知续打偏差；仍然存在续打策略不够强、采样分布不匹配等误差。首动作也不得根据该世界的分叉结果回写到原始采集轨迹。

## 本轮实施约束与验收范围

**先做版本冻结的小规模标签试验，验证信息边界、覆盖和成本。**下面都是工程建议。

| 项目 | 具体约束 |
| --- | --- |
| 决策窗口与候选 | 在看分叉结果前冻结选择规则；可在线按预设概率接受首个合格窗口，接受后不替换，每局/类型限额也提前固定。记录这种停止采样规则，它不等于所有窗口均匀采样。基线动作必须保留。2—4 个候选只支持在该候选集合内比较，不能据此排除集合外的改进。 |
| 分叉与终点 | 每个候选从同一完整快照独立克隆；后续动作、吃碰竞争和胡牌均重新运行。不能强制沿用原牌谱后续动作或赢家。严格复用生产规则结算。 |
| 信息权限 | 隐藏世界仅用于模拟推进和标签；模型特征、候选筛选和续打策略不得读取它。策略隐藏缓存或随机种子也不能携带牌墙信息。 |
| 原始标签 | 保存本局结束的四家 `ΔS`、终态原因、实际首动作及运行计数；流局正常保留。异常样本显式登记，不把异常当 0 分；同决策比较缺分支时不做完整配对。 |
| 版本和迁移 | 保存规则、代码、特征、动作、初始采样、候选筛选、续打策略、对手池及种子版本；原始世界或其可重建种子只放离线证据部分，与学生输入分开。 |
| 数据划分 | 同牌山、换座、相同决策的候选分支均属于同一 `split_group_id`，不可拆进训练和验证两侧；统计区间也按牌山聚类。 |
| 重复的含义 | 固定完整牌墙且策略确定时，重复执行只是复现检查。只重采策略随机数也不能得到不同隐藏世界；不得把它们记作多份隐藏世界证据。 |
| 效果验收 | 先验收标签合法性、复现、独立牌山预测误差和分层覆盖；再比较完整桌赛积分、名次与可靠性。单局标签改善不保证连庄、后续单局或晋级指标改善。 |

**当前续打策略不是强度上限，但会限制可见的改进。**这种标签评价“这一次改动作，其余按 `π` 续打”；如果大胡路线需要后续连续改变打法，弱续打可能把它打坏。模型上线后每步都改选，会进一步改变轨迹分布，旧标签不能自动代表新策略。后续应以新策略重新采集、换对手池验证，而不是将训练集动作排序准确率当强度。

**完整后验采样器的必要时点更晚。**需要从某个只有玩家观察的真实局面出发，主动生成许多兼容隐藏世界以在线搜索、精细比较单点动作或覆盖罕见观察时，才需要专门的条件采样机制。自然模拟样本可以先开始；它只隐式提供当前 `D` 的条件世界分布，不能冒充真实强对手下的后验，也不能把一个世界的分叉最优当成该观察已知的正确答案。
