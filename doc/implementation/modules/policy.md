# `policy` 实施说明

## 交付结果

实现确定性的 `WeightedHeuristicPolicy` 与只保留紧急动作的 `SafeFallbackPolicy`。输出完整 `DecisionPlan`，不执行提交。

## 第一阶段排序

优先采用分层规则，再在层内使用少量可解释权重：

1. 官方规则允许且当前应当胡的动作；
2. 硬规则和抓打圈约束；
3. 最低向听数；
4. 最大加权有效牌数与成牌收益；
5. 手牌灵活度；
6. 最小吃碰加速风险；
7. 桌内积分、剩余单局和当前名次只做保守风格调整。

杭麻没有点炮胡时，防守分主要衡量弃牌是否帮助下家吃、他家碰、庄家或直接名次竞争者提速。不要照搬日麻放铳危险度。

## 降级规则

- 先从 `RuleAnalysis.emergency_candidate` 构造保底计划。
- 主策略超时、异常、空计划、重复候选、引用规则集外动作或已拒绝动作时，应用层使用保底计划。
- 明确 409 拒绝后重新调用策略，`decision_id` 不变、`revision` 增加、已拒绝动作必须排除。
- 第一阶段不接入 LLM、模拟器或价值网络。

## 完成定义

- 同输入同配置结果逐字节可复现。
- 每个候选有总分、分项和中文可读原因。
- 所有规则候选均出现在排序或有明确过滤原因；紧急候选不被普通 Top-K 删除。
- 1 秒窗口基准和异常回退契约测试通过。
