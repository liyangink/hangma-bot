# 一次摸牌分值候选 v1

本批实现独立离线候选 `one_draw_value_v1`，以 `weighted_heuristic_v2` 为对照。目标是改善已经听牌时的积分效率；立即合法胡仍优先，尚未听牌时保持 V2，杠补与普通摸牌分开比较。规则修复基线为提交 `10a7f79`、`hangma-mvp-v5-four-white`，公式依据官方指南 v23 和 2026-09-08 `fan-calc` 原始响应。

## 1. 当前决策范围

同一后续弃牌下，把每种可胡进张的“未见张数 × 本人条件净得分”相加，称为本版的条件分值质量。该数值的单位是张数乘积分，用于候选排序。未见牌包括他家暗牌，未来还可能被别人摸走；它不是成胡概率或整单局积分期望。

- V2 首选为普通等待且结构向听为 0 时，才比较同向听的弃牌、过、吃和碰。
- 吃碰保留全部后续弃牌路线；不同弃牌方案互斥，只取单个方案的合计值，不能求和。后续实际弃牌用相同排序尺度，并可随新公开信息重新选择。
- 同值依次按未见张数、动作键排序。该组原 V2 的白板奖励、熟张等分项保留供审计，但不参与本组排序；完整桌赛实验检验这一取舍。
- V2 首选杠时保持原计划，其余普通等待排序也不跨过杠的位置。补牌有更早得分的优势，本批没有给它臆造概率或时间倍率。
- `value_weight=0` 完整返回 V2，`1` 启用候选；本版不接受插值参数。缺失或截断事实返回原计划；增强异常、超时返回已有 V2 并记录降级。取消继续传播。

历史样本 B、C、D 用于检验拆对子和吃碰取舍，G 用于防止一律留对子。A、F 检验继续立即胡，E 检验四白/豪华七对分值事实，但其杠选择本批保持 V2。原始可见请求和原审计行摘要见 `tests/fixtures/policy/one-draw-value/`；没有向策略提供未来摸牌或他家暗牌。

## 2. 规则事实与边界

条件成胡路线（`ValueRoute`，动作生效后，在指定条件下摸一张便可合法胡的见证）由 `hangma` 生成。正常摸牌与本次杠补用不同来源标记；不构造假定的 `PlayerObservation` 或已确认 `WinDescription` 来计未来分。

共同条件是：所属候选与指定后续弃牌已经生效，单局没有被别人结束，本人没有再执行其他动作，随后从声明来源摸到路线的有效牌并立即胡。路线记录摸前暗牌、副露组数、链次数、链内飘白次数和摸后爆头。番数、四家净变分复用同一套手牌分解、生命周期、`YouCaiBiKao` 资格和结算算法。

| 位置 | 已实现增量与含义 |
| --- | --- |
| `HangmaRules.analyze` | 可选关键字 `value_limits=None`；默认不生产分值事实、不增加成本 |
| `ValueAnalysisLimits` | 全请求 `max_expansions=2048`，每候选 `max_routes_per_candidate=128`；正整数工作量上限，不使用时钟 |
| `RuleCandidate.value_facts` | 可空 `CandidateValueFacts`；含当前胡的立即结算、条件路线、覆盖状态、问题说明 |
| `ValueRoute` | 条件结算、固定为 0 的路线向听、有效牌及未见数、后续弃牌、机器可读条件、条件见证标记 |
| 覆盖状态 | `complete/partial/unavailable` 只相对一次未来摸牌范围；空路线不代表整单局无机会，非完整必须给原因 |
| 旧 `CandidateFacts` | 保持原最佳向听、有效牌、最佳后续弃牌的口径，V0/V1/V2 不消费新字段 |

每个等待手牌计一个节点，静态任意听最多 34 次检查预留 34 个节点，每种未来牌再计一个。预算全请求共享；分组或节点到上限明确标记 `partial`，不把搜索顺序造成的缺失当零分。规则可选增强失败不改变原 `RuleAnalysis` 的合法性完整度，问题只记入分值事实。紧急路径不依赖增强。

未见计数扣除手牌、四家牌河/副露和本动作新公开牌；飘链白板另作物理上界，避免历史牌河不完整时多算白板。已知牌墙没有可摸牌时不提供未来路线。手牌包含或不包含单列摸牌的两种观察形态等价。

## 3. 审计和评估装配

`application.audit_codec` 双向保存条件结算和完整路线。旧记录缺 `value_facts` 仍读为 `None`，不补算为零；默认关闭时序列化也不新增该键。规则版本、动作键和观察绑定沿用所在决策请求，禁止跨牌面复用。

`MatchExperiment` 和 `MatchDriverConfig` 增加同名可选工作量配置。离线驱动先固定原始预算、准备独立紧急动作，再执行规则和策略；规则分析计入 `elapsed_ms` 与截止时间，不能在分析完成后重置预算。首版仅一次摸牌枚举，没有多步搜索；真实窗口可用性另外测量，逻辑时钟效果实验不能冒充时限验收。

`drive_match(..., on_hand_completed=None)` 可选回调使用模拟器公开 `export_hand` 导出已完成单局的 `round_no/winner_seat/fan/score_delta`；四家净变分按座位 0—3，不混淆累计桌分。实验入口启用分析后另写 `hands.jsonl`，不改变 `MatchResult` 语义。赛后数据不回流为本次策略输入。

离线命令示例（具体冻结配置见[实验文件](../../review/one-draw-value-2026-09-08/experiment.json)）：

```bash
PYTHONPATH=src:. python scripts/evaluate.py matches --experiment review/one-draw-value-2026-09-08/experiment.json --out /tmp/one-draw-value-results
```

本批未向正式运行配置增加策略预设，没有切换或重启自由赛进程。

## 4. 实验门禁与未覆盖项

开发批次预先固定 32 个根种子，每个四次换座、V2 与候选各运行一场，每场 8 个单局，共 256 场桌赛。底分 1，`YouCaiBiKao=false`，三个对手均为 V2。主指标为完整桌赛净增积分，置信区间以根种子聚类；同时报告胡牌次数、番数和运行异常，不能仅凭最大牌型判优。

该批属于开发集，不是独立确认集。若主指标和运行门禁支持继续，冻结候选后再用独立种子确认，再申请真实测试房验证。没有显著改善就保留稳定策略，不依据几个历史样本改变默认值。

本批不实现：非听牌时的多步分值路线、等待期间的生存风险、杠与保留七对的跨速度取舍、风险控制下放弃立即胡、全场榜单/晋级目标。普通等待的单步分值改进是否转化为完整桌赛优势，必须由实验回答。
