# 下一阶段提案：用完整续打标定轻量动作价值

2026-09-10 顺序更新：用户明确要求先收敛均衡、稳定的启发式 V2，再开始模型训练。本提案的价值模型阶段后置；当前执行范围与复核结论见[均衡启发式计划](../../review/heuristic-balanced-2026-09-10/README.md)。保留完整续打作为离线比较工具，不以模型训练为前置条件。

用途：在用户确认方向后，接替连续手工排序消融，统一比较高分牌型、成胡速度和等待风险。线上仍从规则合法候选中快速选择并保留紧急动作，不让大规模续打或 LLM 进入线上窗口。正式赛配置继续固定 `YouCaiBiKao=false`。

## 为什么需要调整研究重心

早期路线保留、持续双路线、有限等待三类候选的独立确认都未达到稳定替换门槛。另一方面，完整条件续打已证明首次财飘同分的后续加分、E 暂缓暗杠等局部机会，也存在“不吃以保七对反而明显减分”的反例。问题不是简单缺少某个大牌奖励项：同一个动作同时改变分值、等待长度、再改牌的机会和他家终局风险。

现有一次摸牌标尺缺少未成胡后的剩余价值；固定存活系数没有为较长等待校准；分开叠加向听、进张数及分值门槛容易重复计算速度成本。再增加手工优先级很难给出一致判断。

## 分四步执行

| 步骤 | 可 review 的产物 | 验收与停止条件 |
|---|---|---|
| 1 统一样本与未覆盖清单 | 当前观察、实际窗口、所有合法动作、条件来源、公开计数、续打策略/规则/种子版本；标记已听/距听步数与墙余量 | 新样本只用可见信息；保持原始记录不覆盖；先补短墙、明杠/补杠和原窗口恢复的缺口 |
| 2 条件续打价值基准 | 同未知世界的各动作完整续打到终局，分别记录本人胡、他家先胡、单局净分及高分终点；多续打/对手敏感性 | 大牌正例与效率反例同时通过；真实单局终局而非截断补零；不能把指定未来牌当概率 |
| 3 标定轻量评分 | 先用可解释的少量可见特征表/回归，区分动作时序；记录样本密度、校准误差和回退区域 | 不用复杂模型掩盖样本不足；先比较相同观察的排序损失，未见组合或证据薄弱区域回退现有策略 |
| 4 完整桌赛确认 | 冻结评分版本、开发/独立确认/跨对手与实际赛事格式配置、C/Python与真实计时结果 | 按原门槛判断；局部标定误差小不替代完整赛事指标；默认和正式发布仍需人工审核 |

步骤 3 的“价值”是条件模拟对手/续打池下的估计，不是全知最优动作。对手暗牌及未来牌墙可用于离线世界推进，但不能进入评分输入。部署产物应只保存从公开事实可计算的参数与版本，实际模拟器和完整世界留在离线模块。

## 首批优先样本

1. 三类四白首飘同分案例及他家已听牌压力对照；检查第二次加分与被抢先胡的风险。
2. E 缓杠案例，以及自然开发根27的两白暗杠中窗口；前者已有完整条件正证据，后者待恢复原窗口，不能从“分值质量较高”直接贴最优标签。
3. 三个碰/过与两个吃/过案例的速度正反例；检验固定门清奖励是否忽略快速爆头。
4. 原11个未听牌冲突起手；用多种续打方式区分首步错误与后续不会继续保留路线，不能只拿持续七对偏好作为最优教师。

原始证据与已失败模型：[路线研究](../../review/big-hand-paths-2026-09-09/README.md)、[多步机会](../../review/big-hand-paths-2026-09-09/multistep-opportunities.md)、[有限等待](../../review/big-hand-paths-2026-09-09/finite-wait-results.md)、[缓杠](../../review/big-hand-paths-2026-09-09/gang-value-results.md)。

## 尚未解决、不能略过的工程问题

- 当前 `from_replay` 只重建起始发牌，不能直接把中期 `PlayerObservation` 伪装为完整世界。必须先确定公开接口支持的原窗口恢复或条件世界构造方法，保留可见历史与物理守恒，再开始给中期请求估值。
- 构造起手需要按自然数据的覆盖率单独报告，不能把大量稀有大牌样本的等权均值当作赛事效果。
- 评分的标定集、模型选择集、独立完整桌赛确认必须分开。当前已用至1180000系列的种子范围和各批条件哈希见研究账本；未执行的预留范围也单独记录。
- 先设每批固定案例数/世界数并保存每批实际耗时，再扩大最有信息量的缺口。不能承诺某个日期必然达到+10/桌，或靠重复确认等待一次正结果。
