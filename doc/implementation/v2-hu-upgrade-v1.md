# V2 底座的有界等胡升级

本实验只把已经验证的等胡增量接到冻结 V2，配置名 `v2_hu_upgrade_v1`。其普通吃碰杠弃牌不使用一次摸牌分值排序，风险表和 10% 安全余量均不重新拟合；正式运行默认保持 V2。

## 原因与实现

上一轮三策略同牌山诊断中，一次摸牌候选相对 V2 的平均差为 −3.508 分/桌，等胡增量为 +3.375，组合后差接近零。前者区间仍包含零，不能断言其普遍更差；另一个预先固定的独立对照也支持等胡增量为正。因此本轮以 V2 为底座单独确认，而不从旧确认集中挑选有利牌山。

`V2HuUpgradePolicy` 继承同一个有界增强实现，仅选择 `ComparableHeuristicPolicyV2` 作为本实例的完整底座。规则证明、校准分组、风险分值、保持爆头等待、已拒动作过滤、截止时间与取消语义全部复用。关闭 `upgrade_weight` 精确返回 V2；增强失败的审计文字也明确记录 V2，不能写成一次摸牌候选。

风险表依然是 `hu-upgrade-risk-v1`。适用范围限 Base=1、`YouCaiBiKao=false`、`hangma-mvp-v5-four-white` 和默认 V2 模拟对手池。表的估计性质、保持等待的条件和下一摸重新决策的限制见[首版完整说明](hu-upgrade-v1.md)。本轮没有新增规则算法、公开观察字段、线上模型或模拟调用；C/Python 规则源未改动。

## 固定实验

开发 32 个新根种子 950000–950031，主确认 128 个新根种子 960000–960127。每个根均为 V2 与候选各四次换座，每桌八单局；四种逻辑初始庄家按根等量。风险校准、上轮全部效果样本与本轮样本不重叠。

主要指标仍为完整桌赛净增积分，按根聚类计算配对差和区间，并逐单局核验四家增量之和等于桌赛终点。旁路记录每次等胡的条件及实际后续结果；逻辑时钟实验不替代真实 1/3 秒窗口和测试房门禁。不得根据中途成绩修改参数或提前停止。

实验冻结、结果与结论见[本轮报告](../../review/v2-hu-upgrade-2026-09-08/README.md)。本候选尚未进入正式运行预设，不能仅凭分值分析正确或最大胡分上升自动发布。

## 测试房接入与新证据限制

现在可在 `mode=test_room` 显式选择该策略；应用层在原预算内启用规则分值分析，并检查平台实际规则配置。启动配置见[一候选三 V2 模板](../../configs/test-room-v2-hu-upgrade.example.json)，完整运行门禁见[接入核验](../../review/v2-hu-upgrade-runtime-2026-09-08/README.md)。

同日其他工作发现抓打圈投影与官方轨迹有差异，本分支已复现模拟器允许圈内其他玩家手切。冻结的旧模拟结果仍可复算，但风险参数和净积分改进不应外推到正确抓打圈或实战。首轮真实房间用于权限、协议和预算核验；修正规则投影后需要重做风险校准与独立效果评估。该问题没有在本次入口接入中被隐含宣称已修复。
