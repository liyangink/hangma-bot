# 启发式策略路线与候选命名

本文规定后续报告的**展示名**，用于避免把牌效 V2、牌效加等胡以及 R18 的第二个候选都简称为“v2”。展示名不替代运行配置里的 `strategy`、候选源码摘要或冻结发布包 ID；旧审计和历史报告保持原名，以免破坏可追溯性。

| 后续统一展示名 | 代码中的精确策略名 | 含义与状态 |
| --- | --- | --- |
| **`PAIEFF-B02-CORE`（牌效基线）** | `weighted_heuristic_v2` | 第二代可比牌效启发式，稳定对照 |
| **`PAIEFF-B02-HU01`（牌效等胡）** | `v2_hu_upgrade_v1` | 在牌效基线之上加入有界等胡升级；既有 Tier-A |
| **`OPTY-R18-C01`（机会候选一）** | `r18_integrated_positive_v1` | R18 综合机会候选第一冻结版本 |
| **`OPTY-R18-C02`（机会候选二）** | `r18_integrated_positive_v2` | R18 综合机会候选第二冻结版本，现活动研究父代 |

命名由三段构成：**路线**（`PAIEFF` 牌效或 `OPTY` 杭麻机会）、**来源代际**（`B02` 基线代或 `R18` 演化批次）、**候选修订**（`CORE`、`HU01`、`C01` 等）。新的机会实验沿用 `OPTY-R18-C03` 等序号；只有演化协议或父代路线换代才改变 `R18`。修复相同候选实现而改变可执行内容时，必须新建修订名或发布包 ID，不复用旧身份。

报告中的“强于”必须写明精确比较对、对手池、规则与指南版本、统计单位、区间和证据环境。`OPTY-R18-C02` 在 H/M 离线面板中优于 `PAIEFF-B02-CORE`，**并未证明优于 `PAIEFF-B02-HU01` 或近期真实对手池**。上线资格、活动研究父代、测试授权分别记录为状态字段，不编码进展示名。

实网运行仍使用既有 `strategy` 和 `expected_policy_release_id`。尤其 `OPTY-R18-C02` 当前绑定完整发布包 ID `e82f904c2c1fb70beea3f195110c8b2db0648971ed3eaa9bfcbed1b6543de486`；展示名本身不能授权装配。来源见[冻结四臂确认](../review/r18-four-arm-evaluation-2026-09-23/CONFIRMATION.md)和[发布包契约](implementation/interface-contracts.md#481-r18-累计机会候选真实入口冻结包2026-09-23)。
