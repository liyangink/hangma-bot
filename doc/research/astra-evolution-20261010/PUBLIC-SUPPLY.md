# 公开实体约束自然缺张：先核事实与用途信用

固定28个自然输入的事实探针已完成：两个不同房间的5个保白目标存在理想缺张2、受限缺张3的差异，3项限定报价归因均降低目标信用。全部差异属于P0非首选弃牌根，目前没有新排序、实际改选或收益证据。下一步核完整排序与同距离下的进张形状；不把该距离直接替换成结构向听或所有未来路线的距离。原P0、规则与已批准包保持原件。

## 已确认的源码范围

公开实体约束自然缺张（`PublicSupplyNeed`，固定用途在公开未见实体数量上界约束下至少还需的自然牌张数）与[理想自然牌缺口](../../../UBIQUITOUS_LANGUAGE.md)并列。未见池含他家暗牌及不可摸保留区，只能限制实体上界，不能当牌墙概率。来源不精确时不得把保守下界当作精确配额；未知、未计算和固定目标无结构解分开。

当前[标准型入口](../../../src/hangma_bot/hangma/_grouped_native.c:304)将未来自然牌配额设为每码四张减本人暗牌，内部同一分组内核已能逐递归消耗完整配额且缓存键含配额。[用途结构](../../../src/hangma_bot/hangma/route_structure.py:110)有意计算固定目标的理想缺张，由调用方负责公开容量；它没有规则错误。

P0的[jointwait](../../../prebuilt/vip-s03-rulefix-p0-compiled-v1/source.py:202)用当前改善码的正容量合计形成目标门，却没有证明该目标后续需要的重复实体能同时满足。新增白的普通型一步支持与保留白自然目标的用途信用分列；普通等待节点没有自动展开完整的新白后弃牌、再摸续行，所以不能宣称白救援已经充分计价。

## 最小反例与新增白边界

以下人工结构夹具已由独立纯Python同内核数学回归验证，不是自然P0改选证据。本人三副露，等待手为东、南、西、白；牌河中东南西各两张，加本人手持一张，合计本人可见各三张，即每码未见仅一张，另有可完整取得的新自然面子。

保留当前一白、不将它用于目标块时，原自然面子缺张为2，东南西都是原改善码且各有正容量；但任何已有字牌刻子都还缺两张，剩余实体只有一张。固定用途的受限缺张为3。再取得一张东后，持东变两张而未见东变零，受限缺张仍为3；新改善集合应转向能启动可完成新面子的码。

| 新增白数 | 剩余自然实体缺张 | 新增白也计成本的总获取下界 |
|---:|---:|---:|
| 0 | 3 | 3 |
| 1 | 1 | 2 |
| 2 | 0 | 2 |
| 3 | 0 | 3 |

因此该例不能证明含新增白的全路线下界从2升到3，更不能删除白救援。固定目标的理想缺张不超过可再取得白数、且总白不超过四张时，缺失自然槽可逐一由新白替代；这个结构论证不证明合法胡、倍率、圈态或实际可取得白。

回归口径另须区分：原无公开耗尽约束的结构缺张在增一白时最多下降一张；受限距离可因白打通另一个分解而下降多张，本例即3降至1。受限距离只核新增白下单调不增、以及新增白获取数加剩余自然缺张不低于原理想缺张，不能套用前者的一张下降上限。

能继续核的是固定自然目标的独立信用：原目标不允许新增白参与块内，却可能按较短自然缺张赋予成熟度。修正需连同该目标改善码重算，同时保留普通白支持、结构向听、七对及直接胡支付；不能只改距离、沿用旧宽度，或把所有受限目标统一减分。新改善集合可能更宽，整体排序方向仍待测。

## 有限探针与候选条件

本批复用[已闭时机诊断](TT-TIMING.md)的28个固定新自然输入，不扫描新增来源或使用结算标签。保留同一次完整P0原计划，对当前合法普通弃牌根逐项记录理想缺张、受限固定用途缺张、额外白各项成本及父实际使用的目标；不要求数牌首选或精确同分。每窗仅对至多两个父实际用到且有距离差异的目标补齐改善码和用途信用归因，未完整覆盖所有根时不报新首选。

私有实现需公开受控的同内核事实入口、保持旧默认语义并独立绑定源码；不得在策略里复制递归、取得私有闭包函数或覆盖旧运行根。本人普通弃牌只是把已知实体从手牌移到牌河，不使未见库存增加。给定自然牌后的同目标改善查询须持牌加一且未见上界减一；额外白每张计获取，四白特殊资格仍不由该事实决定。
