# 当前单白完整桌赛标签的有限可识别性试验

当前规则下能够取得不同弃牌的完整后继现金标签，但本批尚不能证明公开历史增加预测能力，也没有产生更强候选。八个固定来源中七个自然入口、一个缺额；十四个续打完整闭合。五个非零差里四个原数学摘要已经不同，唯一摘要相同的差仅发生在后续单局。今晚仍使用[已冻结的正式P0](PLAN.md)。

## 用途和事前范围

本试验只判断数据形态是否值得继续讨论。反事实分叉（`Counterfactual Branch`，从同一世界应用不同动作后配对续打）使用当前唯一规则、原P0及原三个对手；从固定公开窗口继续至原16单局桌赛自然终点。它不是十桌160单局的候选效果评估，不对七点均值或晋级收益作推断。

来源固定为刚闭开发池的H1/M1至H4/M4，均取原P0的座位变体0、桌0。每源最多前256个全座决策窗口；选择首个当前和累计白数均为1、普通摸牌、完整9–512事件历史、完整规则与全根保护通过的点。父首选必须为数牌；备选固定为原排序中第一个不同数牌弃牌且保白、结构向听相同的根。结构向听相同不等于有效牌、胡牌形状或原评分相同。无入口不替换来源，不按后续现金选择窗口。

八源全部完成、自然回收并封闭选点后，才读取完整原后缀和结算。各点两臂强制恰一次，之后本家回P0，对手保持原P0/RF1与座位。父臂必须复现全部原后缀动作、16单局完整导出与终分；子臂也必须自然到原终点，全部动作合法。学生候选输入仅为现有公开编码：334维摘要、每事件14维序列及每候选184维编码。来源身份、未来牌墙、他家暗牌及标签均在输入之外。
