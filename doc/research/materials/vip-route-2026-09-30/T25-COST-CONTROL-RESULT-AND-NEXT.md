## 从实际行为学到了什么

**此前的辅助惩罚确实能压过更合理的路线取舍，但不能据此认定它全域有害。** 下表全部是从相同公开起点到当前单局结算的净分差，统计对象不是完整桌赛。

| 起点 | 世界 | T25 − 真 T24 | T25 − R18 |
| --- | --- | ---: | ---: |
| 单白、近七对与助攻费冲突 | 原来源 | +15 | 0 |
| 同一单白起点 | 相容变体 | +21 | +10 |
| 零白、主路线同值 | 原来源 / 变体 | 0 / 0 | 0 / 0 |
| 零白、较宽普通出口 | 原来源 / 变体 | 0 / 0 | 0 / −8 |
| 双白、普通与七对选择 | 原来源 | −8 | 0 |
| 同一双白起点 | 相容变体 | +40 | +24 |

单白首选真实从弃 6 饼改为弃南，原世界修回 R18；变体由父 −1 变为本人二番 +20，R18 +10。普通出口的既有后续损失仍在。这没有证明七对应该一律优先。

双白第一手双方仍弃 3 万，变化发生在后面。原世界第 12 个共同推进帧之后、`seq275`；变体第 20 个之后、`seq291`。两份完整输入分别同父完全相同：候选弃 1 条，父弃 3 条。手牌相同、墙余分别 41 / 39；普通型均为零向听、公开进张 13 张 / 6 码。弃 1 条保留的七对是一向听；弃 3 条为二向听。完整返还取消了约 0.520 / 0.236（变体 0.530 / 0.239）的不同助攻扣分，改变了排序。

原世界最终他家一番变二番，我方庄家支付 −8 变 −16；变体则我方一番 +24，父被他家二番截断 −16。**这是分歧之后整条策略路径的结果，还没隔离成“只改这一弃牌”的因果效果。** 不能把 −8 全归给这一手，也不能把 +40 全当作该手收益。派谱结果不能倒灌成线上知道他家手牌或未来摸牌的事实。

## 根的取舍与后续执行顺序

**停止本批自动扩桌，保留 T25 作为混合效果的机制对照。** 作者前冻结的规则要求其他路径不受损才继续自然桌；双白原世界下降，故本批没有绕过该规则。这是事前资源安排，不是“任何麻将候选必须所有世界全赢”的算法准入定理。不得因一个负世界永久丢掉候选，也不得因几个正世界授强度。

下一批不再立即调用作者调权，先用不变源码购买新信息：

1. **归因已有双白分歧。** 以两个已经闭合的真实共同观察作来源，原分歧前缀保持不变；至多 10 条单局，用 A（R18）、T24 / T25 各自正常 C、各自首手后共同 R18 的 B，区分这一手和后续打法。不按结算挑新的世界，不要求两世界同号。原结果仍只属一个母牌山。
2. **再决定自然验证的新批规则。** 现有四起点已经曝光，不再作为修改和确认的同一题库。若继续验证 T25，则先冻结标准 A 探针及共同自然配置。最多 10 窗 × T19 / T24 / T25 三包 = 30 评分；T19 是明确共同参考，不冒充 T25 真父，另纯读比较真 T24 与 T25 的同输入行为。可用当前共同配置绑定两个待测包，避免重复探针。
3. **买新来源而非继续针对旧题修分。** 使用作者前预冻结且尚未执行的 `2026102901…2026102908`、H/M 两池、四换座、每桌 8 单局。先两母根、父子合计至多 64 实际实例；两根结束后集中核验并决定是否再开后两根。若标准 A 未观察首选差，则依现行工具门只做明确的一母根记录覆盖，父子各至多 16 实例，不能冒充完整增强验证或绕开门禁。
4. **留存按行为和分层效果。** T25 保留正反向签名、源码和复算链，不凭小批合计排名。当前三家族五活动公式不变，T25 是保留的未晋升对照；新来源未验证前，不替换稳定候选。普通出口、当前胡、多白及竞争终局分别报告，缺三白、四白层记未知。
5. **有新失败再派一个窄作者。** 若新来源仍显示辅助费用与可见路线信息冲突，给作者短的成对动作/后续反馈，研究费用校准或联合取舍。不要按牌码、母牌山、`seq` 写补丁，不把公开未见容量直接当作牌墙或对手概率。

以上是下一批的安排，**不是其 START 或新评分**。新批必须先写冻结选择、身份、预算和停止条件。本批未证明自然完整桌优于 R18，未出现四番以上突破，也未通过独立来源、完整赛事、动作时限、接线与发布门。

## 如何减少流程时间

**一次批末集中核验，关键节点集中交评。** 这次同核心 40 条续打只用约 79 秒；没有为每份文档、评分缓存或同一规则重复派评审。后续应继续：作者只负责新公式；机械消融可明确标成根构造的实验控制，不必购买一次作者来改一个赋值；同工具复测复用已验证核心和真父缓存，但结果和实际输入仍留存。

依据[一手方法复盘](./evidence/t19-methods-transfer-recap-1/METHODS.md)：EoH 用外部实际评价决定留存；ReEvo 用具体成对反馈并计评价成本；FunSearch 保留分层表现不同的行为簇。它们支持保留本次混合信号并补新来源，不能保证后续增强或赛事前三。当前最有用的结论是：**辅助费用已经成为可定位的取舍来源，下一步应测试其可迁移性，而不是无区别再抬大牌奖励。**
