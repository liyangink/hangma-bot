## 2. 固定事实与可进化公式

**固定框架回答“有什么、是否合法、已知到哪一步”，候选回答“怎样取舍”。**玩家观察（`PlayerObservation`，本座依法可见的信息）是候选输入上限；模拟完整状态（`WorldState`）只属于离线评估器。

| 内容 | 固定框架拥有 | 候选可进化 |
| --- | --- | --- |
| 结构 | 真实分牌型向听、自然对子／四张、用途约束缺口、逐码进张与交集 | 速度、宽度、白板保留、自然牌形与转换成本的权重、阈值、非线性组合 |
| 路线 | 条件见证、爆头／链资格、覆盖范围、相同证据去重 | 普通出口与高番选择的联合取舍、路线集合聚合；不改事实含义 |
| 动作 | 全合法根、吃碰全部跟打、给定杠补转移、当前胡结算 | 根与后续弃牌一起评分，胡／继续、碰杠节奏与分支偏好 |
| 执行 | 只读视图、版本绑定、限额、完整返回校验、合法性复核 | 一个候选内可有多个子函数；整套候选一起评价 |
| 评测 | 抽样、冻结、配对、损失账、确认隔离与门禁 | 只消费开发反馈，不读取确认结果及隐藏牌 |

最小入口沿用 `score_actions(view) -> ScoreBatch`：输入同一权威版本的只读事实；输出全部输入动作键各一个有限评分点及有界解释，无文件、网络、随机、时钟或提交副作用。评分点越大越优，**不是实际积分，不跨候选比较绝对量级**，沿用现有 `ActionScore` 语义。非法、漏项、异常、`ABSTAIN` 或超量使研究桌未完成；不能直接复用会补紧急动作的生产包装器。

当前 `ActionValuePolicy.choose` 会把评分失败转成合法紧急计划，离线 `strict_policy` 单独开启不能识别这种内部降级。研究包装须显式抛出并记录评分状态，以故障注入验证“未完成”；不能只查 `is_emergency`，因为正确首选也可能恰好是紧急候选。

| 拟议视图字段组 | 单位、权限与空值语义 |
| --- | --- |
| 身份与阶段 | 观察／规则／配置／事实语义／执行器摘要；明确弃后等待、吃碰待跟打、杠补前后。赛事压力字段不进入候选视图；庄家、公开副露和墙余可读。 |
| `actions` 与分支 | 根键、跟打键、条件事件键；各层声明应有数量、完成数量及截断原因，不能只交付评分容易的动作。 |
| 结构与用途 | 自然牌计数 33 维、白板总数／使用数／保留数、目标块与将条件、目标阶段、自然缺口（张）、必需后续摸牌及弃白动作数（次）；全部来自真实全手。 |
| 进张与证据 | 规范 34 牌序的集合及容量（张），自然集合排除白；不同路线保留交集。`None` 是未知／未分析／不适用并附原因，空集合是已分析为空；精确与保守容量分开。 |
| 资格与支付 | 已见证、尚未排除、已证关闭、未分析；当前胡四座净积分按座位 0—3，单位积分点。结构成立不等于合法高番必达。 |
| 覆盖与预算 | 根机械、结构、资格分别声明范围；待给定事件、缺实现、缺输入、预算截断分别记账。规则只收工作量限额；截止时间由外层使用单调时钟，持续时间用毫秒。 |

每份权威修订只调用一次候选。先沿用执行器现有 100,000 计数操作、4,096 局部集合项及 32 KiB 解释上限；新增事实展开另冻节点／分支上限，全部计入总耗时。这些是起始工程限额，不是已满足 1 秒／3 秒的证据。正常机械缺口不能冒充可接受的未来不确定性。

## 3. “自然牌形”如何算对

**真实向听不改；另给“指定目标下自然牌缺口”，不能删白后把残缺手牌称为真实向听。**现有 [`hand_analysis.py`](../../src/hangma_bot/hangma/hand_analysis.py) 的普通／七对数学继续权威；新增计算放在 `hangma` 内复用分组求解，不在策略另写规则。

以合法弃后等待态为基准：自然计数为非负整数向量 `n`（33 维），白板数为 `w`，固定副露数为 `m`，满足 `sum(n)+w=13-3m`。杠副露按一组折算，实体四张另记；摸后或吃碰待弃的多一张状态先展开合法动作，不能再虚加一张摸到第十五张。

对指定目标，枚举使用现有白板的不同分解。若目标所需自然牌向量为 `t`，定义缺口

\[
D=\min_{t\in\mathcal T}\sum_{i=1}^{33}\max(t_i-n_i,0).
\]

`T` 明确目标块、将、白板角色、副露限制及自然实体牌四张上限；保留实现最小值的见证与不同进张集合。这里只数理想条件下至少要补的自然牌，忽略对手截断和行动时序，不能叫成胡概率。

| 用途条件 | 目标与数量守恒 |
| --- | --- |
| 不专留白（`k=0`） | 普通完成目标是剩余面子＋将；七对是七对且 `m=0`。全部 `w` 可百搭，真实向听仍调用原规则结果。 |
| 保留 `k=1..w` 作后续转换 | 普通前驱目标是 `4-m` 面子＋一张保留白；七对前驱是六对＋一张保留白且 `m=0`。块内**恰好使用** `w-k` 白，由分解见证验证；其他使用量另列 `k` 档，不在同档偷改。其余 `k-1` 白是后续待合法飘弃的实体牌。 |
| 多白守恒 | 普通前驱自然目标大小为 `12-3m-(w-k)`，故 `D≥k-1`；需补 `D` 张自然牌、弃 `D-(k-1)` 张自然牌及 `k-1` 张白，末态仍为 `13-3m` 张。七对同理取 `m=0`。 |

不同目标的 `D` 不能直接当同一成胡速度：`k=0` 目标是完成胡结构，`k≥1` 目标是 13 张折算前驱。前驱 `D=0` 仍至少需要一次合法摸牌／补牌才可能胡；补一自然牌再弃白也只是到达新的等待态。视图须同时给出目标阶段及尚需的动作下界，实际资格另验，不能把前驱成形写成已经胡。

例：`123w 123t 123b 78w 白白` 共 13 张。`k=1` 时一白参与面子、一白保留，面子缺口可为 0；`k=2` 时块内不用白，补 `6w` 或 `9w` 后弃一白，自然缺口为 1、待弃白一步。后者是否能计财飘、是否继承爆头，由规则生命周期证明；结构算式不授予资格。白板从未预绑定某张孤牌。另有“四自然对＋三自然单张＋两白”也是 13 张，现有七对向听为 0，不能用“至少五自然对”硬排除。

自然牌码分为**结构推进集合**与**当次合法胡集合**。给定自然摸牌后，胡分支由唯一规则源判资格及结算，不再强制弃牌；非终局续行才经合法弃牌／飘白比较同一用途的 `D`。因此 `D=0` 前驱仍可有胡牌宽度。按牌码保留两集合的并集、交集与标签，不能重复计数。角色更新绑定原目标、实际用白数及转换键：`k≥2` 的同用途前驱分支合法弃一白时，`w,k` 同减一、块内用白量不变；其他角色改变另标转换，换目标本身不算同目标进展。

容量永远从包含全部保留白的真实手牌计算。公开未见容量包含他家暗牌，不能除以墙余冒充概率；保守下界为零也不能证明耗尽。未来合法动作过程尚未验证时保留“结构见证／资格未分析”。

## 4. 全动作怎样比较

**同一公式看到全部合法动作及其损失，不按动作族各选冠军再拼接。**固定框架只合并相同条件、用途、结构和资格的重复见证；不同转换成本留存。普通／七对共有进张按牌码并集计宽度，保留路线标签，不能把重叠出口各算一份独立好处。

吃碰以“根动作＋全部合法后续弃牌”对比 `Pass`；吃碰未摸时若规则另允许暗／补杠，先杠再补牌的条件续行也交给同一候选评分，直接弃牌表不是全部续行。候选用自己的联合评分选后续，再给根排名；实际获裁决后，以新权威观察重算，不盲执行旧计划。旧 `best_followup_discard` 仅保留兼容用途，新策略不得把它当唯一分支。碰不摸牌；明杠补摸；暗／补杠不跳其他人。鸣牌相对供牌座位可跳过 0／1／2 个原行动座位，框架记录事实，不预设固定压制奖金。

杠的补牌未知，以相容牌码的**条件分支**给出补牌后合法动作与结构范围；不能挑最好一张当必然，也不能因未知删掉杠。人工种子先在每个给定补牌分支选择最佳合法后续，再以分支评分下端及改善牌码数联合评估杠；这是可进化的保守启发式，不是积分下界或概率期望。容量未知的相容牌码不能漏掉。固定四张导致的顺子、豪华七对路径关闭要显式呈现。墙余不大于 20 的杠限制只消费 [`action_families.py`](../../src/hangma_bot/hangma/action_families.py) 当前规则源及证据范围，不新增普适策略阈值。

胡和继续都输出同一无量纲评分点：真实胡支付先按底分归一、经候选声明的变换成为一个输入特征，不能直接加到任意代理分上。人工种子偏向保住良好听牌，有限等待爆头、财飘和杠链，一般不拆完成搭子；墙余、庄闲与公开副露只提供粗上下文。这些与“五自然对”“吃碰降自然缺口”“听牌再暗杠”均是可验证经验，不能成为屏蔽合法动作的硬规则；例外也须入损失账。

候选无权绕过唯一规则源、工作量守卫及提交前复核。研发先备合法紧急动作以满足接口安全约束；一旦走未获得完整候选评分的紧急回退路径，就记研究失败，不能因正常首选与紧急动作同键而误判。正式部署仍须保持原截止时间、单场单个在途 POST、拒绝后权威刷新与结果不确定时禁止盲重发。

## 6. 评估补口与停止规则

**先验事实正确，再看机会得失，最后看完整桌积分。**微观层核查守恒、白分配、容量交集、实际胡资格及结算；与独立枚举、官方金例／`fan-calc`、生产转移差分相互校验，不能只比较共用同一错误函数的两个入口。规则依据沿用 [`RULES_EVIDENCE.md`](../../src/hangma_bot/hangma/RULES_EVIDENCE.md)、2026-09-15 抓取的 [v34 正文](../../doc/references/official-guide-v34-content.txt)及 [v35 差异记录](../freematch-deep-dive-20260925/OFFICIAL-GUIDE-V35-G266-RULE-DELTA-2026-09-29.md)；本提案没有新增官方确认。

机会账至少保护普通出口、四对两白、普通／七对爆头前驱、多白、胡／继续、吃碰阻断及三类杠；同时记录错失普通胡、盲等、拆形、他家先胡和流局。高手历史牌谱只作学习与诊断，原后续牌墙不能承诺反事实结果，题库成绩不能冒充总体。专长候选可按预登记家族容量留档作父代，仍须全桌与确认门。

自然账沿用运行时 `config.Rounds`、完整同墙四换座及两个冻结异质对手池，候选每个窗口持续续打；按根统计，保留正负尾。独立确认根从未用于选权重、算子或题型；样本充足性由根级方差、最小有意义改进、区间精度及预登记查看次数决定，不凭固定桌数宣布通过。缺行、机械缺口或回退不从分母删除。

| 首批待验证未知 | 哪种结果要求回头 |
| --- | --- |
| 用途缺口能否区分真实转化成本 | 数量不守恒、独立枚举反例或遗漏合法跟打：修事实框架，停止候选比较。若事实相同却专家理由不同，先定位缺哪项可见事实。 |
| 人工种子能否保普通出口又有限等大牌 | 机会足够仍全胡，或普遍盲等／拆形：改联合公式与分支；正反例都保留，不凭一个成功牌谱加奖金。 |
| 当前预算是否支持全动作事实与排名 | 正常动作反复截断、超量或丢失分支：优化表示和等价计算，重新测量；不得退回最小向听预选。 |
| EoH 是否比人工种子产生有效新行为 | 等预算仅生成重复行为、开发改善在新根消失，或普通损失吞掉高番增益：停该家族，复核目标／测量，再决定是否新增事实。 |
| 自然改进证据是否足够 | 区间仍容许实质退步、结论由单根支配或对手池反号：不晋升；保留敏感性结果，按原预登记补样或结束。 |

每批先冻结候选调用与评测预算、最大查看次数、最小有意义差、可容忍机会损失及停止／补样规则。预算耗尽而证据不足就结束为“不确定”；发现机械错误立即返修；达到预登记无效界限就停止该方向。不能反复查看同一确认池或事后降低门槛，不能把“再加特征、再调参数”自动当作下一批理由。

最大风险是结构指标仍会诱导漂亮牌形和盲目等待，外部评测只能揭示、不能预先消除这种偏差。尚缺用途约束事实、独立种子与新视图的完赛证据、实机预算及审计完整性。获准恢复后的启动顺序应为 T0、T1、人工种子与严格完赛，然后小批 EoH；本提案不恢复任何暂停工作。
