# T46：自然面子准备的有限事实

**已实现明确反例支持的自然面子准备（`NaturalSetPreparation`，只看剩余自然面子还差几张），没有产生新候选或强度结论。** 新内部模块复用现有唯一标准型数学；只接真实等待手牌，保留所有白板库存，不把准备程度当向听、合法爆头或未来收益。本子任务没有改旧路线目标、动作规则、计分或策略；受控评分视图集成由根代理另外验收。

## 实现范围

**事实只回答一个固定问题：不用白作百搭、不要求将，剩余自然面子准备到什么程度。** 公共纯函数是 [`analyze_natural_set_preparation`](../../src/hangma_bot/hangma/natural_preparation.py)。输入必须是规范牌序的真实34维计数和副露组数 `m`；每码整数0—4，总数严格为 `13-3m`。已摸多一张的动作态须先通过规则枚举合法弃牌，不能直接套本入口。布尔值不能冒充计数或副露数。

| 冻结字段 | 数学含义及单位 |
| --- | --- |
| `natural_counts33` / `whites_held` | 真实暗牌的33种自然牌计数／真实白板张数；不添加未来白板 |
| `meld_set_count` / `sets_left` | 既有副露组数／剩余目标组数 `4-m`；吃碰杠各按一组折算 |
| `target_natural_size` | 固定自然目标实体数 `3*(4-m)`，单位张，不含将 |
| `natural_draw_lower_bound` | 自然补张下界 `D`，单位张，不是需要摸几次 |
| `natural_discard_lower_bound` | `sum(natural)+D-target_natural_size`，单位张；不证明存在合法弃牌过程 |
| `natural_need_improvement_codes` | 按规范顺序，补一张自然牌使同一个目标 `D` 严格下降的牌码；排除本人暗牌已持满四张的第五张 |
| `target_distance_evaluation_count` | 首次构造该结果的距离请求数，最多34；缓存命中不新增请求 |

独立语义版本是 `vip-natural-set-preparation/1`。结果使用冻结数据类及不可变元组；缓存最多2048个完整等待牌形。校验在缓存前执行，避免 Python 的 `True == 1` 绕过实体域校验。输入不含副露内牌值或牌河，因此改善码只说明手内数学推进；公开剩余容量、已暴露四张、当前窗口和资格仍由已有规则／投影证据处理。

## 数学依据及边界

**没有新增分组算法。** 定义目标集合 `T` 为 `4-m` 组自然顺子／刻子、每种自然实体最多四张的全部固定目标。若当前自然牌计数为 `c`，则：

```text
D = min(t∈T) Σ_i max(t_i-c_i, 0)
  = hangma._standard.need(c, 0, 4-m, False)

自然弃牌下界 = Σ_i c_i + D - 3*(4-m)
```

第二式来自目标实体守恒；在达到最少补张目标的理想条件中，多出的自然实体必须离开手牌。白板既没被用作百搭，也没从真实库存字段中删除。固定副露、目标面子数和“不含将”的语义，不能拿不同目标的缺张数直接当成完整胡牌速度。

`D=0` 只证明当前自然牌可以组成目标面子；零白时并没有白板，更没有合法爆头。持四白时也不假设将来再摸第五白。事实不预测白板出现、他家先胡、实际牌山或赛事积分；不决定是否应等待大牌。这些权衡仍交给后续联合公式。四副露时自然目标为零组，`D=0` 是正常数学边界，也不是新增胡资格。

标准型面子、牌码和四张物理上限依据仓库已有[规则证据](../../src/hangma_bot/hangma/RULES_EVIDENCE.md)；官方指南依据沿用已有 v23／v27／v34 对应条款与抓取记录，没有本批新增官方确认。距离只调用现有 [`_standard`](../../src/hangma_bot/hangma/_standard.py)，自动继承已安装同语义原生后端或 Python 退路。

## 明确反例及旧事实对照

**T38的零白弃牌反例被准确区分，同时原真实向听保持不变。** 两个共同等待手牌均普通向听0、七对向听4：

| 首手后的等待手牌 | 自然补张下界 | 自然弃牌下界 | 同目标改善码 |
| --- | ---: | ---: | --- |
| 拆五条刻子：`2w3w4w 4b6b 9b9b9b 5t5t 7t8t9t` | 1 | 2 | `5b`、`5t` |
| 弃六饼保刻子：`2w3w4w 4b 9b9b9b 5t5t5t 7t8t9t` | 0 | 1 | 空 |

这说明新事实能表达原目标缺少的自然准备差别，**不证明固定“保刻子”规则普遍较强**。归因与原世界后续白板路径已在 [T38／T40](./T38-T40-NATURAL-PREPARATION-GAP-AND-CAUSAL-RESULT.md)记录，不重新授予候选信用。

复核旧数学原型的30个直接等待后态、15个不同手牌，所有补张下界、目标实体数、弃牌下界与改善码逐项精确一致。其中10个持白后态还与当前旧普通型“保留全部真实白板”的等待前驱目标一致。原型跳过的两处杠补根本批也没有冒充直接等待态；未来集成应在每个真实补牌及合法弃牌后态调用本函数。

## 实际测试和局部计算量

**新入口15项测试通过；与旧用途结构测试一起30项通过。** 命令为：

```bash
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src .venv/bin/python -m pytest \
  tests/unit/hangma/test_natural_preparation.py \
  tests/unit/hangma/test_route_structure.py -q
```

实际结果：`30 passed in 1.46s`。测试均经公开函数验证行为，不读取私有缓存。覆盖范围：

- 独立枚举33种刻子和21种顺子，组合成一／两组自然目标，并拒绝目标的第五张；在50个真实等待牌形上核对最小缺张及逐码改善集。该证明限定一／两组目标，不夸大为全部四组域穷举。
- 110个真实等待牌形覆盖五种副露数和全部可行白库存；其中85个持白牌形与旧全白保留标准前驱目标的距离、目标实体数、弃牌下界、改善码一致。
- 零白反例、数牌孤张和字牌孤张的宽度差、自然四张、纯四白库存、四副露零目标、不可变返回值、非法总数、负计数、第五张、布尔和浮点输入。
- 隔离解释器禁用原生库，现有 Python 数学退路仍得零白反例 `D=1`、弃下界2、改善码 `5b/5t`。

对旧30个后态作新进程局部测量，使用 `c_grouped` 后端。15个不同牌形初次构造合计510次距离请求（每牌形34次），本函数持续时间合计 **1.323915毫秒**、单牌形最大 **0.216833毫秒**；15次重复缓存调用合计 **0.017125毫秒**、最大 **0.001459毫秒**。时间使用本地单调计时。输入和代码在该次测量前后摘要不变，旧生成数学字段全部相同。

上述只是限定牌形的函数成本，不是冷启动最坏牌形、全部条件图节点、完整评分、并发赛事或动作时限结果。已有持白目标数学可能共享底层缓存，新增入口仍需被实际完整评分输入和原生／Python性能验证覆盖；不能用约0.22毫秒宣称完整策略已过门。
