## 2. 结构事实

**自然牌缺口（`NaturalTileNeed`，指定用途与目标下理想条件中至少还需补的自然牌张数）不是实际向听或摸牌概率。**唯一数学实现在 `hangma`；真实普通型／七对向听不改。

入口 `analyze_route_structure(counts34, meld_set_count) -> RouteStructureFacts` 返回不可变事实，接受 `sum(natural_counts33)+whites_held=13-3*meld_set_count` 的等待手牌。杠折算一个面子，实体第四张仍在公开库存。多一张行动态先沿同源规则展开合法动作，不能虚构第十五张。此入口不读网络、文件、时钟或完整世界。

| 事实 | 单位与边界 |
| --- | --- |
| 自然计数／对子／四张 | 33 维自然牌计数；四张算两对；保留规范牌码 |
| 牌型、保白量 `k`、块内用白量 | `k=0..w`；块内恰用 `w-k`，独立枚举核验；不预先绑定某孤张 |
| 目标阶段 | `complete_structure` 为剩余面子＋将或七对；`waiting_predecessor` 为剩余面子或六对＋一白，七对要求无副露 |
| 自然缺口 `D` | 指定目标所需自然牌向量相对实持牌的最小正缺口和；前驱自然目标大小 `12-3m-(w-k)`，故 `D>=k-1` |
| 条件动作数量 | 前驱补 `D` 自然、弃 `D-(k-1)` 自然和 `k-1` 白；完成目标自然弃下界 `D-1` |
| 必需终点摸牌 | 前驱 `D=0` 仍需合法摸牌／补牌才可能胡，不与完成目标直接比较成胡速度 |
| 条件缺口推进牌码 | 固定用途补一自然牌使缺口下降；不是合法续行或高番资格证明 |
| 见证与范围 | 无分解见证明确 `distance_only`、见证为空，不填虚构结构 |

补张下界仅对指定自然补张路径成立；新增白板、吃碰、杠另开转换，不作为所有胡路线的全局下界。精确用途求解必须核验物理每码四张与数量守恒。

实际进张分别保存**结构推进集合**和**直接合法胡集合**。后者由给定摸牌后的同源规则判断，不强制再弃；前驱 `D=0` 不意味着胡宽度为零。并集按牌码去重并保留交集与用途。换目标本身不能伪装为同目标进展。

公开容量从真实全手与公开事实计算，包含他家暗牌。精确零可证耗尽；保守下界零／未知不能删相容码，也不能除以墙余冒充概率。

## 3. 全动作与条件见证

**全部当前合法动作参与排名；未来条件声明范围。**吃碰保留全部合法弃牌及未摸时合法暗／补杠，获裁决后重评真实观察。杠补按相容牌码展开，不挑最好补牌当必然，不因未知删杠。正常机械缺实现、必需输入缺证据、未来未知、深度外和工作量截断分开。

`analyze_waiting_draw_witness` 为合法弃后等待态提供局部条件见证，显式指定墙余、抓打限制和下一本人摸牌，标记 `local_witness_only`。它不证明能活到该摸牌，不是完整公开事件链或 P2 门证据。未裁决结构分支须先给定完整裁决条件，不得直接提升为已发生状态。未知资格可作为未知事实交候选；当前动作或必需输入无法正确形成时研究桌未完成。

仅查询胡资格时可用同源窄入口 `analyze_waiting_hu_witness`：只返回合法胡、即时结算、问题及被摸牌码的容量变化，不返回未计算的向听、进张或完整后态。内部 `HandWinEvidence` 由同一成胡数学产出；动作门禁、爆头及结算仍复用唯一规则实现。优化必须与完整见证逐项对照，不靠删除根或续行提速。

他座终局内部字段 `other_draw_replacement: bool | None` 区分已给定普通摸（False）、补摸（True）、未摸／来源已消费（None）。`expected_discard_seat` 不能证明他座刚摸牌，吃碰未摸暂态不能接受自摸终局。该字段不扩展官方观察或事件。

## 4. 评分与严格执行

**只开放一套联合排名代码。**候选类型 `vip_route_heuristic_v1`，视图 `vip-route-scoring-view/1`，入口 `score_actions(view) -> ScoreBatch`。旧 `/4` 输入合同不变。新冻结类型 `VipRouteScoringView` 以有界图描述根与续行，子节点先于父节点；根表与同次合法候选对应，各节点说明阶段、条件、用途与覆盖，不预选最小向听分支。

每个输入动作键恰一条有限评分与有界解释。评分点越大越优，不是实际积分，不跨候选比较绝对量级。当前胡真实支付作为有单位的事实经候选变换参与取舍，框架不得直接混加任意代理分。

执行器新增精确类型入口 `score_vip_route`，复用静态检查、工作量、完整输出及跨调用状态守卫；旧 `score(ScoringView)` 不改。严格研究包装对异常、弃权、超量、非法和漏项显式失败，不能复用生产内部紧急降级。完整评分首选恰与紧急候选同键不是回退，未获得完整评分而走保底才是研究失败。

起始候选额度 100,000 计数操作、4,096 局部集合项、32 KiB 解释；规则建图另声明节点／分支／深度限额。全部计算计入实测决策耗时。逻辑时钟不能证明官方1秒／3秒可部署；有价值但慢的机制可另冻有界研究额度，最终部署版本仍须实机验收。
