## 1. 交付与使用范围

**唯一新增入口只接受真实全手的弃后等待态。** [route_structure.py](../../src/hangma_bot/hangma/route_structure.py) 提供 `analyze_route_structure(counts34, meld_set_count)`，语义常量 `ROUTE_STRUCTURE_SCHEMA_VERSION="vip-route-structure/1"`。输入按 `CANONICAL_TILE_ORDER`，白在最后；每码为整数 0—4，总数必须为 `13-3m`。摸后或吃碰待弃的 `14-3m` 状态由调用方先枚举合法弃牌，禁止额外虚加摸牌。

结果 `RouteStructureFacts` 与逐目标 `RouteStructureTarget` 均不可变。每目标分别记录普通型／七对、保留 `k` 白、块内恰用 `w-k` 白、目标阶段、目标自然总量、自然缺口及条件弃牌下界。真实普通型向听复用 `_standard.need`；真实七对向听复用原 `_chiitoi_pairs`，有副露时七对不适用为 `None`。自然四张统计成两对，但不授予豪华胡资格。

| 字段 | 本批准确语义 |
| --- | --- |
| `natural_need`／`target_natural_draw_lower_bound` | 理想条件补入多少自然实体能达到**该固定目标**，单位张；不含新增白、鸣牌转换及他家截断。 |
| `target_natural_discard_lower_bound` | 完成目标 `D-1`；前驱目标 `D-(k-1)`，单位弃牌动作次，实际资格未验。 |
| `target_white_discard_lower_bound` | 完成目标为 0；前驱为 `k-1`，单位弃白动作次，实际飘白资格未验。 |
| `requires_terminal_draw` | 前驱为真；即便 `D=0`，仍需要下一次合法摸牌／补牌才可能胡。它不是所有胡路线的摸牌次数下界。 |
| `conditional_need_improvement_codes` | 给定自然码补入手牌后，**相同块数、相同实际用白数**的缺口降低，规范顺序去重、排白及物理第五张；尚未验证合法弃牌过程。 |
| `witness`／`witness_status` | 恒为 `None`／`distance_only`：精确距离已算，本版本未生成可审计分解见证。不能把 `None` 当已分析为空。 |
| `target_distance_evaluation_count` | 本次目标距离请求数，包含逐码条件补张；不是后端展开节点、执行器计数操作或耗时。 |

普通与七对逐码集合保留各自标签；交集不相加成独立宽度。当前合法胡集合、合并后的合法宽度、公开未见容量、白角色迁移及全动作分支覆盖由规则组合层验证。结构模块不读取公开副露实体、完整世界、文件、网络或时钟。它只以 `m` 折算固定面子，调用方仍须以全手和公开实体校验总体四张容量。

## 2. 恰好用白与分组上限距离的等值依据

**可以复用允许少用白的标准距离，但不能声称后端直接生成了恰用白见证。** 设目标共有 `s` 个槽位，白上限 `u=w-k`，本模块合法输入保证 `0≤u≤s`。

取任一最多使用 `u` 白的目标；若只用了 `v<u` 白，就从它的 `s-v` 个自然实体中任选 `u-v` 个换成白。顺子、刻子和将的块形不变。目标自然向量按分量只减不增，所以 `sum(max(t_i-n_i,0))` 不增。未来补牌配额 `4-n_i` 也不会增用：原目标若满足实体四张上限，替换后的目标仍满足。目标实体中的白总量为 `u`，其余保留白始终留在真实库存。

因此“恰用白”的最优值不大于“最多用白”的最优值；恰用目标又是最多用目标的子集，反向不等式成立，二者相等。该论证是距离的等值证明；不会把后端允许不用的多余白虚构成已完成实际弃白，也没有产出特定分解。

对前驱，自然目标总量为 `12-3m-(w-k)`，当前自然库存为 `13-3m-w`，差为 `k-1`，故 `D≥k-1`。补 `D` 张自然、弃 `D-(k-1)` 张自然及 `k-1` 张白后，留一白，总量仍为 `13-3m`。完成目标多一实体，故等待态 `D≥1`，自然弃牌下界为 `D-1`。二者阶段不同，不能直接拿 `D` 排成胡速度。

## 3. 七对目标的独立缺口

**七对目标只推广原规则的补对数学，不判断当前胡资格。** 目标对数 `p` 为完成时 7、前驱时 6。设自然对子数 `N=sum(n_i//2)`，自然落单数 `S=sum(n_i%2)`，`r=max(0,p-N)`，可用白数 `u=w-k`，则

`D=max(0, 2r-min(S,r)-u)`。

先选择最多 `p` 个现成自然对，四张同码按两对。剩余 `r` 对最多使用 `r` 个自然落单；自然落单与白各填一个槽位，其他槽位由未来自然牌填。已有奇数自然码为 1 或 3，补一实体不超过四张；新纯自然对可放在未占满牌码，33 码和最多 7 对提供足够位置。恰用白也可由上一节的自然替换论证保证。

测试的七对 oracle 与此闭式不同：逐码穷举目标自然计数 0—4，以奇数目标需一白为代价合成目标对数，再允许剩余白自对，最终要求白**恰好**用满。它不调用被测距离函数或现有手牌求解器。

## 4. 验证结果

**新数学与现有回归均通过。** [test_route_structure.py](../../tests/unit/hangma/test_route_structure.py) 包含 15 项测试，验证下列范围：

- `123w 123t 123b 78w 白白`：普通前驱 `k=1` 为 `D=0`、仍需终点摸牌；`k=2` 为 `D=1`、待弃白一次、条件推进仅 `6w/9w`。完成目标另列全部自然出口，前驱推进空集合没有屏蔽终点出口。
- 四自然对＋三自然单张＋两白：真实七对向听 0，完成缺口 1；未引入“五自然对”硬筛选。
- 中张孤牌与孤字比较、白不预绑定、自然四张两对、普通与七对集合重叠、物理第五张排除、所有可行白库存 0—4 与副露数 0—4、等待态和目标守恒、输入类型与不可变结果。
- 普通型独立穷举全 33 码的一面子／一面子＋将目标，枚举每槽自然／白角色和实体四张上限；41 份手牌逐 `k` 校验距离和全部自然条件进张。

- 隔离解释器禁用原生模块加载后，结构入口继承现有 Python 数学退路，关键两白距离及进张保持一致。
