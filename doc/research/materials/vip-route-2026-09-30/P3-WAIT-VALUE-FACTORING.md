# VIP 胡／等同轴积分：按人类判断顺序拆账

结论（2026-09-30）：**“等”不是一个固定加分，也不能只扣他家先胡概率。**当前合法胡由 `HangmaRules` 精确给出四座结算；继续动作要对未来首次互斥事件、到达时间、届时牌形与终局积分逐项取期望。以下是第一版通用本座单局净积分的工程合同，尚无校准通过的模型，也不改变已冻结的赛事压力暂不干预策略的范围。

## 动作与首次事件在同一积分轴

玩家观察（`PlayerObservation`，本座当时依法可见的手牌及公开事实）为 (o)，合法动作为 (a)。若 (a) 是当前胡，(Q(o,a)) 就是规则模块当前四座结算中本座的净分。其他动作使用首次竞争事件（`First Competing Event`，本次动作后本人下一次有选择的窗口或更早的公开终局）的互斥划分 (E)：

\[
Q(o,a)=\sum_{e\in E}\Pr(e\mid o,a)\,V(o,a,e).
\]

这个等式只是按互斥事件拆分期望的记账恒等式；**当前没有证据证明估计出的概率或续行价值准确**。每条事件质量非负，总和必须为 1。普通摸牌按牌码逐码区分；同一张摸牌后的普通型、七对、爆头、财飘只是资格或番数标签，不能重复占事件概率。首次事件已终局时，(V) 是该终局四座结算的本座净分；仍有本人行动时，(V) 是对应条件后态的胡或继续价值，不把尚未胡写成零分。

| 人类判断 | 第一版可计算事实 | 必须估计或保留未知的量 |
| --- | --- | --- |
| “现在胡多大” | 当前胡的合法性、番数、四座积分 | 无；规则分析不完整则拒绝本次估值 |
| “等会不会大很多” | 已声明摸牌条件下的合法胡与四座结算、普通型／七对牌形 | 到达各条件分支的概率、非胡后的继续价值及远期高番兑现 |
| “大概等多久、牌山够不够” | 当前官方墙余、保留区禁杠及动作链规则 | 多次本人行动的到达时间、他座先胡和流局截尾；公开未见容量不是实际牌墙概率 |
| “三家副露危险吗” | 三家公开副露、弃牌与手牌张数 | 他家暗牌、实际听牌和接下来会不会先胡；公开副露只可作为风险特征 |
| “我是庄家吗” | 庄家座位与同源结算 | 庄家身份对未来等待／竞争危险的增量，需要庄闲分层校准 |
| “现在积分有压力吗” | 当前桌内积分、赛事阶段与排名事实 | 第一版暂只审计，后续赛事目标变换需另行冻结与验证 |

## 计算顺序与不可跳过的边界

1. 对同一玩家观察取得**全部**合法动作及各自条件根。当前胡直接采用规则四座积分；吃、碰、明杠只把“若获裁决”的后态当条件，不提前当已执行事实。
2. 对每个继续动作建立互斥首次事件：本人普通摸牌及牌码、可行动响应、杠补摸牌及牌码、鸣牌获裁决后的未摸跟打、他座先胡、流局。响应中的未获裁决与获裁决必须分开。条件分支缺事实时报告覆盖缺口，不填零或让 R18 正常接管。
3. 估各事件发生质量及等待时间。墙余和公开未见牌张数限制可能性；后者只有公开容量含义，不能直接充当隐藏牌墙的真实摸牌分布。对手副露和庄家身份进入可见特征，同时保存预测依据、样本支持和校准误差。
4. 若到达下一本人窗口，合法胡用当时同源规则结算；若选择继续，则评估可保留的普通速胡与大牌路线，以及墙余和对手风险下的条件末端（`Tail Estimate`，有界展开未终局时的后续积分估计）。不能只给番数或有效牌宽度固定奖励。
5. 对所有合法动作回到同一本座净积分单位比较，并在审计中分列直接胡积分、各首次事件质量、等待时间、条件末端、信息缺口。赛事阶段／积分压力可记录，但不进入第一版排序。

## 把人类的“再等几巡”落到同一账本

当前胡是确定的本座净积分。继续等则必须区分“下一次本人有选择的窗口”与“已经胡成大牌”；两者之间可能还要经历数次摸牌、响应和弃牌。每到一个新的本人窗口重新比较胡与继续，不能把今天观察到的一条高番路线当作未来必然能到达的胡牌。

对每个继续动作，账本至少显示以下四列，且四列共同决定动作排序：

| 要回答的人类问题 | 模型输出 | 校验办法 |
| --- | --- | --- |
| 能比现在胡大多少 | 按合法胡型互斥汇总的终局本座净分分布；未胡的条件末端单列 | 对已到达的胡逐例与规则四座结算对拍，不能把“可能达到的番数”当已获得积分 |
| 大概需要多久 | 到本人下一决策窗及目标胡的等待步数分布，而非一个固定平均巡数 | 按庄闲、当前向听、进张宽度和白板数检查分层误差 |
| 剩余牌山够不够 | 每个等待步数对应仍有可摸牌机会的质量及流局截尾 | 墙余减少时，超过可达步数的路线质量应归零；公开未见张数不能直接代替真实牌墙分布 |
| 等待期间会失去什么 | 他座先胡、本人可能支付、鸣牌获裁决／落空及其他中断的互斥概率与净分 | 依三家公开副露、弃牌及庄闲分层校准；副露只是可见危险线索，不等同听牌事实 |

实际估值仍按上面的首次事件方程递归：先分配“下一本人窗口／他座先胡／流局”等互斥质量；到达下一本人窗口后，再用当时的新观察重新估所有合法动作。这样“继续等两三巡才能胡大牌”的价值来自逐层存活与条件续行，而不是把大牌番数加一个固定奖金。研究期可用有界末端估计截断计算，但必须把截断质量、估计来源和误差留在审计里。

庄家身份有两处作用：规则结算直接改变当前胡和失分金额；等待期间被他座先胡的代价可能改变速胡偏好。第一处可精确计算，第二处需要分层数据验证，不能手写“庄家一律速胡”分数。当前桌内积分及赛事排名压力会改变人类对高风险高番路线的选择，但按已约定的第一版范围只读取和记录，不改变通用本座净积分排序。若后来接入赛事目标，需要另定义“前二晋级／正分奖池／海选累计积分”的目标函数，并用对应赛制的完整桌赛或阶段验证，不能直接把负分乘一个追番系数。

## 当前证据决定的否证顺序

[已开机会根](./evidence/p3-multi-opportunity-20260930/README.md)证明同一张下一摸牌仍可因后继牌形不同而产生不同终局，本次静态分支末端探针也未改善动作值。新[结果盲事件框](./evidence/p3-event-mass-20260930/README.md)已轮换庄家并出现三家副露；但墙余不大于 28 张的可决策首窗只有 3 根，极晚巡不能据此校准。先用拟合池检验类别质量守恒和本座积分守恒，再在诊断池按庄闲、墙余、三家副露、有无多白机会检查概率、等待时间及动作差方向。若诊断失败，保留失败结果并修模型或补未覆盖场景；确认池必须先冻结全部合法动作预测，再开结局。之后仍需新 VIP 自行续打和同墙四换座完整桌赛；本合同本身不是能力提升证据。
