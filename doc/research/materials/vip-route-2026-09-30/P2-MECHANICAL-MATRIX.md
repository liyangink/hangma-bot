# VIP P2 正常动作机械矩阵（实施中）

日期：2026-09-30。目标配置固定为官方 `BaseScore=1`、`YouCaiBiKao=false`。本文是内部条件转移的当前审计，**P2 机械完成门尚未通过**；“局部闭合”只表示写明的给定事件组合通过对拍，不代表该窗口所有可能公开事件已闭合。

## 依据与口径

规则依据为[官方指南 v34 正文快照](../../doc/references/official-guide-v34-content.txt)（2026-09-15 抓取）及[本仓规则证据](../../src/hangma_bot/hangma/RULES_EVIDENCE.md)；[v35 版本记录复核](../freematch-deep-dive-20260925/OFFICIAL-GUIDE-V35-G266-RULE-DELTA-2026-09-29.md)于 2026-09-29 仍未取得 v35 全文。本文不把开源麻将实现当作官方依据。

输入分为三类：当前玩家观察（`PlayerObservation`，本人暗牌与公开事实）、给定条件事件（`GivenEvent`，研发明确假定已经发生的一张摸牌或裁决）和完整模拟世界（`WorldState`，含他家暗牌和未来牌墙）。此量具只使用前两类，不读取完整模拟世界。`route_transition.py` 的条件状态不是官方观察，不生成新的官方序号、事件时间或假快照。当前“完整”只针对被声明的机械单步和给定组合，不能推出整单局穷尽。

模拟器差分又以 8 条“本人起手弃白→抓打圈→他座公开动作→本人再摸”的固定种子对拍圈主与合法动作全集。它发现并修正他座 3 弃白后本座 0 本应直接普通摸、条件阶段却仍停在 `PUBLIC_WAIT` 的缺口；此自然反例已经锁入[差分回归](./P2-SIM-DIFFERENTIAL.md)。这不关闭上表抓打圈全部组合。

同一差分量具再用完整 136 张物理牌构造他座先碰、跟打、绕桌普通摸弃、拿到第四张后补杠并补摸的连续路径；条件态只读已发生公开动作，与模拟器本座可见副露、手牌数、墙余和圈主逐步相等。它补充上表“他座补杠”单例，但不代表多杠或期末组合全过。

新增 30 个自然牌山的[混合鸣牌和杠连续差分](./P2-SIM-DIFFERENTIAL.md)：6,054 个实际窗口内包括 91 次吃、83 次碰、3 次补杠、2 次暗杠与 5 次杠补摸，27 次流局及 3 次他座胡均与模拟器逐步一致。它扩大了连续组合的实测分母；未抽到本座胡、明杠或末墙多杠交叉，故上表任何“未闭”格均不因此改为完成。

种子 `34` 的受控完整单局在他座 3 自摸时，以模拟器投影出的完整 `round_ended` 公开结算终止条件链，四座净分与模拟器相等。原投影曾漏掉已有的公开番数、明细和积分字段，现同步修复；这项核对仍不拿他座暗牌来预测动作前何时胡。

另有一条**构造的整圈公开事件链**：本人弃非白，碰窗与吃窗全过，三家依次给定普通摸、非白弃、碰窗与吃窗全过，再到下一次本人普通摸并重新产生合法动作。测试核四座公开手牌数、墙余每摸减一、本人暗牌不被他家事件改变、未来他家摸牌值始终未知、本地条件身份连续。此链只证一种全过序列的持续性，不当成官方自然轨迹或所有响应组合的闭包。

独立审查发现同一补杠胡条件状态原可凭调用参数替换庄家，使同一番数产生不同四座净分；现绑定根观察 `dealer_seat` 并拒绝不符参数。给定他座已摸牌后的官方 `round_ended` 自摸胡，新增只消费公开完整结算的终局入口：不从他家隐藏暗牌复算牌型或番数。v35 他座暗杠→补摸→自摸胡片段已对拍官方番数、明细及四座积分；这只是一次已发生事件的状态终止，不是动作前预测他座何时胡。

根登记层已经按同次 `RuleCandidate` 顺序保留全部合法动作。吃碰分支来源固定为生产 `CandidateFacts.followup_branches`；缺该事实时保留根并报 `MECHANICAL_GAP`。`ConditionalRoot.pending_condition` 记录下一待给定公开条件，只有当前已知动作/条件确实无法投影才设置 `gap_kind`；两字段都不得单独当成 P2 已过门标志。冻结样本中 47 个旧机械标记均由未来条件尚未给定的占位说明触发，修正后实际根投影失败为 0。持续转移的全部组合仍未认证，P2 门照样关闭。

合法胡根虽在同次候选中，若结算缺失，需按 `value_facts` 原因区分输入证据、搜索截断和真正未接通的机械计算；已加入“链内飘白未知但合法胡存在”的反例，不能把它当作规则转移失败。

## 现有内部 API 与验证

`project_legal_roots` 接收同一次规则分析的观察、`WindowContext` 和合法候选，严格限制目标规则配置；根吃碰/明杠的预列成功分支是结构诊断，不能越过裁决。`advance_given_response` 与 `advance_response_state` 接受完整响应选择，用 `progression.resolve_public_response` 推进当前条件态；鸣牌后被领牌留河或移河须明示。`advance_given_other_draw/discard/gang` 只根据已裁决下一行动座位与给定公开动作接事件，更新四座 `PublicTileView`、墙余、逐码容量与圈主，不创建官方 `seq`；杠后补摸用显式 `replacement=True` 约束来源，未知他座暗牌值不填入状态。给定他座鸣牌还校验其所需隐藏手牌数量不超过**当前精确公开未见容量**；证据不精确则明确 `INPUT_EVIDENCE_GAP`，不按猜测继续。

`apply_given_draw` 要求普通摸牌或杠补来源与待摸状态一致、公开未见容量有精确正值，并禁止未裁决结构分支直接补牌；每次给定摸牌后按当前公开视图重算容量。`given_next_normal_draw` 沿用旧的单次局部见证，必须显式 `allow_local_witness=True`，**不可计入 P2 物理资格闭包**。`analyze_given_self_draw`、`analyze_given_claim_action` 复用生产动作族、成胡分解和结算；`apply_legal_draw_discard` 与 `apply_legal_claim_discard` 共用本人弃牌机械核心，仅接受各自同次合法全集中的弃牌；`apply_legal_followup_gang` 仅执行同次分析列出的杠，并更新公开副露/手牌数/容量。

跨窗口反例已修正：旧入口原先只看本地路径中是否**曾经**出现 `response:`，使“上一次响应已裁决→本人再摸再弃→本次新响应未裁决”能直接假定下一摸并误标为完整条件。现在该入口无论历史路径如何都必须显式选 `allow_local_witness=True`，结果永久标 `local_witness_only`；完整续打只能用当前响应及全部中间公开事件推进到 `NORMAL_DRAW` 后调用 `apply_given_draw`。

条件转移测试见[新单元测试](../../tests/unit/hangma/test_route_transition.py)，独立审查反例见[审计测试](../../tests/unit/hangma/test_route_transition_audit.py)。官方 v18 `chi-gang-draw.json` 核对吃→暗杠→补牌；官方 v35 `peng-followup-1114-1117.json` 核对碰获裁决→未摸合法动作全集→跟打的本座成对快照。生产 `ValueRoute` 核对暗杠/吃碰后给定摸牌的立即胡分数。负例覆盖缺成员、错触发牌、多人 `blocked`、留/移河条件、非法本人吃、未摸先弃、错座位摸、弃白直接换圈、物理第五张、明杠未裁决就补牌和跳过碰窗。候选与本人暗牌冲突归 `MECHANICAL_GAP`，不混为观察证据不足。以上是有限组合证据，**不是完整官方赛事轨迹验收**。

## 当前状态契约与下一步

最小条件状态已经携带本人暗牌、四座当前 `PublicTileView`、根时点原视图、精确或保守的逐码容量、本人座位、已裁决下一摸/弃座位、抓打圈主、当前响应触发牌和窗口、吃摊/碰码、链内飘白、爆头、墙余与本地路径身份。`PublicClaimEvidence.retained_in_river` 保留每次领取牌的明确留/移河条件；无条件时返回输入证据缺口。`WindowContext.conditional_discard=(seat, tile)` 已由总体架构作为受控入口加入生产动作族，条件弃牌不冒充带官方 `seq` 的 `PublicDiscard`。详见[条件状态契约](./P2-CONDITIONAL-STATE-CONTRACT.md)。当前实现没有读取他家暗牌、未来牌墙或 `WorldState`。

剩余机械缺口按顺序处理：

1. 他座明杠获裁决→给定杠补摸→弃牌，及已给定暗杠/补杠→杠补摸的无暗牌码公开事件入口已实现。他座明/暗/补杠各有一条本座视角官方自然片段对拍公开机械；暗杠后他家胡只消费已公开终局结果，不用隐藏牌复算。三类他座杠的其他牌形、连续再杠/胡与任意公开事件组合仍未穷尽，不能将单例视作整格完成。
2. 本座明杠→补牌→立即胡、补杠→补牌→合法弃牌已有[官方 v35 成对快照](./P2-V35-CONDITIONAL-PARITY.md)条件对拍；需继续补更多牌形、杠后动作及多事件组合，不可借两例宣称整格已闭。
3. 响应全过且精确墙余 20 张的流局已可用共用规则结果转终局，并有一条 v35 本座 `21→20` 自然片段对拍；根当前胡与给定本人摸牌后的合法胡共用同源四座结算终局，v35 明杠补摸胡已核根终点。仍缺期末结算、其他胡型和正常摸牌跨任意公开事件链、最后可摸机会的其他自然组合及抓打圈多方组合；`given_next_normal_draw` 仍只能是局部见证。
4. 对他座给定响应，只能用公开容量判物理可能性，无法从玩家观察验证其真实暗牌；这属于观察输入不可区分。碰/吃/明杠真正发生仍须给定官方裁决或明确条件，不能把提议当事实。

下一步优先补第 1 项他座三类杠的更多自然组合与连续后继，再覆盖第 3 项局末与更长公开事件链；第 2 项继续增补本座杠后组合。任何正常格残留 `MECHANICAL_GAP` 都保持 P2 门未通过。
