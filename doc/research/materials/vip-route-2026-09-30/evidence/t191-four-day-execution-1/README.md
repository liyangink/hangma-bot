## 先冻结的投入顺序

1. 对两个最小修复核完整合法根、确定性、输入不变、信用去重和成熟胡等真实增量。机械约束不固定所有历史首选；保白升级正例不能被“能胡一律胡”吞掉。
2. 共同续策三组：A全程原S02；B首手按候选选择、以后S02；C全程候选。先复用14个历史控制，再按不看成绩的公开事实规则补足24个来源。新来源只能称本修复开发新用，不将旧确认来源冒称独立确认。
3. 默认24来源×2相容隐藏样本×3组×2候选=288单局条件筛选上限。最多额外14历史世界×3组×2候选=84单局，分账不混成自然概率。不得中途按分数换题或重抽失败世界。
4. 有机制成立且没有重复严重破坏时，分段8→16→32母来源、四换座的同牌山完整桌开发；每块自然闭合再读结果。比较基线加两候选最多384次桌执行，不自动扩大。
5. 至多固定一个胜者和一次独立确认。默认128全新母来源×4换座×2组=1024完整桌执行是费用上限示例，先核总墙时与剩余时间才派发。强对手压力场景先小规模测成本，不能另自动购买一套1024。

完整桌主要账本为净积分增量＝普通胡收入增量＋四番及以上收入增量＋支付节省。开发允许用真实大牌增益补普通损失，或用普通与支付改善补局部大牌下降；不要求小批各分项均非负。独立确认固定主要指标与来源，开发成绩不并入，区间跨零不得宣布显著增强。规则、时限和正式生命周期门另核。
