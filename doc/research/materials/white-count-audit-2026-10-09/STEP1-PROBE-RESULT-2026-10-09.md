## 2. 结果

**等价性与保护断言（通过）：** κ=1.0 变体（常数不动、仅门控包装）在全部已评分窗口与父版输出逐字段一致——补丁执行链等价成立。六个实变体在非资格抽样 200 窗上门控零违例：**实持 ≥2 白窗口构造性保持父版首选，多白保护按设计生效。**

**三族探针全部零真实改选（负结果）：**

| 变体 | 资格窗改选数 |
| --- | ---: |
| κ=0.9 / κ=1.1（SPEEDCAP±10%） | 0 / 0 |
| VARREF=3 / VARREF=6 | 0 / 0 |
| PURPOSES[1]=1.25 / 5.0 | 0 / 0 |

按[工作计划](./SINGLEWHITE-160-WORKPLAN.md) §5 冻结规则："若报价被其他路线覆盖、无首选差异，记录赢家和价差返回机制诊断，不买阶段桌赛"——**首轮三族探针不进入任何 160 桌赛投入。**

**机制诊断（为什么会零活动）——同分并列事实：** 499 个资格窗中 **195 窗（39.1%）顶部评分完全相同**（0白 146／1白 49），按 `action_key` 字典序裁决；非并列窗的顶部分差中位数仅 0.063 排序点。

1. **κ 在数学上不可能改变同距选择的排序**：κ 是 speedof 的正标量乘子，同距路线的报价差 = κ·(Sᵢ−Sⱼ)，符号不变；κ 只能影响跨距取舍，而 ±10% 未触及任何跨距翻转点。这同时说明[第0步普查](./STEP0-CENSUS-RESULT-2026-10-09.md)的"同距支持次优 8.8%"不能由 κ 族治疗。
2. VARREF（宽度饱和点）理论上可重排同距支持，但 3/6 两档下仍零改选：并列主要来自相同支持摘要或报价被派生结构（红利/先验）拉平，而非宽度定价。
3. PURPOSES[1] 在纯弃牌资格窗内不改变首选：k=1 用途先验影响的是等待结构内部路线竞争，未达翻转阈。

## 3. 对调优方向的修正

**"局部"缺口的主杠杆不是全局交换率，而是并列裁决。** M4 的后半（同分并列任意、action_key 字典序）从代码注释升级为定量事实：约四成资格窗的弃牌选择实际由并列裁决决定，而现行 `rank_continuation_ties` 的辅助质量细分只在 anchor（当前可胡）窗生效（[source.py:599-600](../../../../prebuilt/vip-g37-rf1-compiled-v1/source.py)）。下一个单行为维度算子的自然候选：**把有界辅助质量细分推广到非 anchor 弃牌窗（以支持核为辅助质量、封顶幅度沿用 DIVTOTAL 约束），只细分同分组、不改变不同价组顺序**——与 RF1 已有的 tie 修复同构，机制单一、可先在真实窗口做改选收据。该算子是否立项由人审核，未在本轮实现。

同时确认：单白特异缺口（听后兑现）按[缺口定位](./SINGLEWHITE-160-GAP-AND-DIRECTION.md)仍指向第 2/3 步（框架候选/兑现算子），本轮负结果不改变该排序。
