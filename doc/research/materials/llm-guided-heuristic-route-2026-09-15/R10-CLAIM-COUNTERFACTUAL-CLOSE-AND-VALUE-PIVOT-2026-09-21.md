# R10 吃碰反事实门控结案与动作价值新目标

**结论：固定吃碰奖励和当前单特征门控均已用全新来源否定，停止继续调阈值。反事实执行接缝本身已经验收可用，新目标改为构建“完整玩家可见状态 + 具体动作”的离线动作价值数据与轻量价值模型，并用冻结新来源和完整阶段逐级证伪。** 只有模型在未见动作样本上优于总过牌、总鸣牌和稳定 V2，且冻结后在完整阶段产生正向证据，才生成可晋级候选。

日期：2026-09-21。稳定比较对象：`ComparableHeuristicPolicyV2`。本报告取代继续修补 `route_raw` 阈值、固定 `+8` 奖励或相邻同类公式的指令。

## 1. 已完成验收

### 1.1 原路线候选关闭

路线吃碰专长在全新 `panel_seed=2026092203` 上执行 H/M 各 64 个来源根，共 2,048 张完整桌赛。H 的根级阶段效用均值差为 `+0.001953`，M 为 `-0.025391`，H/M 等权均值差为 `-0.011719`，根级保守差均值为 `-0.015625`；两个分层区间均跨零。339,641 次候选决策中有 707 次首选变化，且无非法、超时、回退或审计缺失，说明失败可归因于策略效果，而非未接线。

证据见 [`R10-ROUTE-CLAIM-NEW-SOURCE-CLOSE-2026-09-21.md`](R10-ROUTE-CLAIM-NEW-SOURCE-CLOSE-2026-09-21.md) 和 [`new-source`](evidence/r10-supervised-evolution/cross-specialist-01-20260921/new-source/)。

### 1.2 动作反事实接缝通过

新增 `ForceFirstActionPolicy`：只在精确 `WindowKey` 上执行一次预登记动作；该动作必须同时存在于规则合法候选和委托策略计划，随后恢复稳定 V2。CF1 在 11 个来源根中取得 H/M 各 4 个有效机会，8 个样本的两臂首动作全部匹配，32 张完整或部分桌赛零内部失败。

CF2 首批冻结上限内取得 25 个机会，未满足预登记的 H/M 各 16 个机械配额，因此没有把首批自身标成通过。CF2-B 只从尚未使用的顺序来源根补足 7 个机会；合并后共 32 个样本，H/M 各 16，吃 15、碰 17，机械检查全绿。补样选择只看自然行为命中，不看续打标签。

32 个样本的主标签 `group_advance_v1` 差为正 4、零 25、负 3；辅助阶段积分差为正 11、零 12、负 9，均值 `-2.09375`。这证明标签可产生正负变化，也显示完整阶段晋级标签极稀疏，单次续打积分标签方差很大。

### 1.3 两类简单门控均关闭

首个岭回归门控退化为 24/24 全鸣牌；8 个开发留出样本也为 8/8 全鸣牌，辅助积分均值 `-5.0`，没有获得选择性。

随后按 Suphx 的动作分解和前瞻事实、Mxplainer/Tjong 的目标与动作分解，补入合法后继分支、支持量、路线数、牌墙和阶段处境等 22 个玩家可见摘要。32 个开发样本上得到单桩：

```text
route_raw <= -0.1807547024365
```

开发留一平衡准确率为 `0.653680`，辅助积分均值为 `+0.40625`。该结果只授权一次冻结新来源验证。

全新 `panel_seed=2026092305` 的 H/M 各 8 个机会中，正辅助标签仅 4/16。冻结单桩选择 2 次鸣牌，平衡准确率 `0.416667`，门控辅助积分均值 `-1.625`，主晋级下界差均值 `-0.0625`，没有满足任何效果继续条件。门控关闭，不实现为完整阶段候选，也不围绕该验证集重调阈值。

第一次全新来源执行暴露可空晋级中点被强制转成 `float` 的缺陷；第二次兼容修订错误替换了类型对象。两批分别以 `CLOSED_EXECUTION_DEFECT_NO_VALIDATION_RESULT` 和 `CLOSED_COMPATIBILITY_DEFECT_NO_VALIDATION_RESULT` 留档。第三批使用仅限旧序列化边界的可空适配，保留 `u=None` 与非空 `u_low/u_high`，16 个样本机械检查全绿。前两批不得混入效果结论。

证据：[`claim-counterfactual-01-20260921`](evidence/r10-supervised-evolution/claim-counterfactual-01-20260921/)、[`claim-counterfactual-02-20260921`](evidence/r10-supervised-evolution/claim-counterfactual-02-20260921/)、[`claim-counterfactual-02b-20260921`](evidence/r10-supervised-evolution/claim-counterfactual-02b-20260921/)、[`claim-gate-calibration-01-20260921`](evidence/r10-supervised-evolution/claim-gate-calibration-01-20260921/)、[`claim-gate-stump-01-20260921`](evidence/r10-supervised-evolution/claim-gate-stump-01-20260921/) 和 [`claim-gate-new-source-03-20260921`](evidence/r10-supervised-evolution/claim-gate-new-source-03-20260921/)。

## 2. 失败原因与文献复盘

**当前主要缺口是价值表示与信用分配，不是再缺一个阈值。** 现有 22 个特征主要是规则模块产生的压缩摘要；它们没有完整表达本人手牌、四家公开牌河、副露位置与牌型、已公开历史等 `PlayerObservation` 信息。开发集上偶然有效的单特征无法区分大量后续价值不同但摘要相近的局面。

32 个开发样本和 16 个新来源样本还不足以支撑多变量模型。单次真实续打虽然保持了同快照、同牌墙和共同随机数，但标签仍受首动作之后的长轨迹分叉影响。新来源 16 个样本的辅助积分差为 `4, 0, 0, 0, -33, -21, -1, -26, 0, 0, 10, 1, 0, -18, 21, -10`；任何一个现有单特征桩在这批上都没有正辅助均值。继续在这些样本上选择特征会把验证集变成开发集。

这与已核对文献的边界一致：

- Suphx 将动作类型拆分，并使用前瞻特征和全局奖励预测处理粗粒度终局信用；它没有证明两个路线摘要即可替代可学习价值。
- Mxplainer 把麻将目标、动作和可学习参数组合起来，证明的是“可信结构 + 校准”的可行性，不是少样本手调权重必然有效。
- EoH、ReEvo 依赖外部评价、多样父代和多次候选评测；在昂贵麻将桌赛中，先让评价信号具备可学习性，比增加相邻公式更重要。
- rollout 的策略改善保证要求真实期望或足够准确的基准后续价值；一次隐藏世界续打不满足这一前提，不能称为真实动作 Q 值。

原始出处与适用边界见 [`ALGORITHM-REAUDIT-2026-09-20.md`](evidence/r10-supervised-evolution/ALGORITHM-REAUDIT-2026-09-20.md)、[`LITERATURE-REAUDIT-2026-09-20.md`](evidence/r10-supervised-evolution/LITERATURE-REAUDIT-2026-09-20.md) 和 [`SEARCH-METHOD-REVIEW-2026-09-20.md`](evidence/r10-supervised-evolution/SEARCH-METHOD-REVIEW-2026-09-20.md)。

## 3. 新目标与明确验收

新目标命名为 **R10-AV1 玩家可见动作价值闭环**：

> 在不读取 `WorldState`、他家暗手或未来牌墙的前提下，用完整 `PlayerObservation`、`CompetitionContext`、规则候选事实和具体吃碰动作编码，学习是否应以该动作替代过牌；先证明动作级新来源可泛化，再冻结为启发式门控并证明完整阶段优于稳定 V2。

它分为五个可停止阶段：

| 阶段 | 产物 | 继续条件 | 停止/复盘条件 |
| --- | --- | --- | --- |
| AV1-0 编码合同 | 完整玩家可见状态的版本化编码；牌种顺序、座位相对化、未知三态、动作条件和规则摘要均有契约测试 | 编码只依赖允许对象；同观察稳定；座位换位按合同等变；不得出现来源根和终局标签 | 信息泄漏、规则重复实现或无法稳定复算时先修合同 |
| AV1-1 清洁采集 | 至少两个全新面板种子，H/M 分层；每层与种子独立记账；顺序命中，不按标签补样 | 训练池至少 128 个有效机会，吃/碰均有覆盖；双臂机械检查全绿；来源根不重叠 | 命中率或成本失控时复盘采样定义，不改标签阈值 |
| AV1-2 价值建模 | 低容量、可审计的动作条件模型；按 `SourceRoot` 分组交叉验证；报告校准、排序和策略效用 | 交叉验证中相对总过牌、总鸣牌有稳定选择增益；复杂度上界冻结；主标签只作稀疏约束 | 分组留出无增益时，回顾 Suphx 奖励预测、信息集续打和 Mxplainer 目标分解；禁止在验证集挑新阈值 |
| AV1-3 冻结动作验证 | 第三个全新面板种子，至少 H/M 各 32 个机会；模型与阈值执行前冻结 | 辅助配对效用均值为正且优于总鸣牌，`group_advance_v1` 下界差不为负；H/M 无明确反向层 | 失败则模型结案；验证集永不回流到同版本训练 |
| AV1-4 完整阶段 | 将冻结模型编译为离线启发式候选，按 24→8→3 级联完整桌赛 | 新来源完整阶段主指标为正，运行与规则门禁全绿；随后才可独立确认 | 任一效果层明确负向或可靠性失败即保留 V2 |

128/64 是本路线的首个工程规模，不是论文给出的最优样本数，也不保证成功。它的作用是让训练、分组交叉验证和一次真正未见验证不再建立在 32/16 的偶然样本上。若 AV1-2 仍受高方差支配，下一步不会直接扩到更多同类样本，而是先实现每个公开快照的多个一致隐藏世界/未来续打，估计信息集条件下的动作价值；该教师仍只把玩家可见输入交给学生。

## 4. 编码边界

AV1-0 首版必须包含：

- 本人手牌的规范 34/杭麻牌种计数及财神标记，保留抓牌位置仅用于规则明确依赖的字段；
- 相对本人座位的四家牌河、公开副露、剩余手牌张数、当前积分、庄位、轮次和公开牌墙余量；
- 本人的爆头、动作链、抓打圈及未知状态；
- 过牌与具体鸣牌的动作类型、领取牌、组成牌、鸣牌后全部合法弃牌分支摘要；
- 普通型、七对、财神、条件路线等由 `HangmaRules` 产生的事实；模型不得另写一套向听、合法动作或计番规则。

禁止输入来源根编号、面板种子、对手实现名称、续打终局、未来事件、他家暗手和未来牌墙。积分向量与公开事件统一转为相对本人座位，避免模型把绝对座号当捷径。所有可空值保留“已知值 / 未知 / 不适用”，不得用零混写未知。

## 5. 模型和 LLM 的职责

首个模型只比较低容量候选：带正则的广义加性模型、深度不超过 3 的树或受限梯度提升。训练目标优先使用配对阶段积分差的稳健回归/排序，`group_advance_v1` 作为稀疏主约束；必须按来源根分组交叉验证，且与全过牌、全鸣牌、固定 `+8` 和单桩同时报告。

LLM 只在以下位置参与：基于训练折正反例提出可解释特征变换；比较两个已执行父代产生 ReEvo 式反思；简化未带来稳定增益的机制。LLM 不生成标签、不接触冻结验证结果后再修改同一候选，也不进入线上动作闭环。

2026-09-21 对 `zai-coding-cn / glm-5.3 / high` 的两次冻结反思调用均在约 15–17 秒后返回 `dsh: TRANSPORT: Connection error`，输入、输出和总 token 均为 0，无可采纳答卷。两次调用留作通道故障证据，主线不等待通道恢复；恢复后从同一冻结提示最多重试一次，仍按外部评价决定是否采纳。

## 6. 执行纪律

1. AV1 的训练来源、冻结动作验证、完整阶段开发和独立确认使用互不重叠的面板种子与来源根。
2. 每次受挫先分类为执行缺陷、测量缺陷、表示缺口、标签方差、搜索失败或真实负效果，再回读对应文献与杭麻规则；不得把所有失败都归成模型不够强。
3. 任一动作级提升都不等同赛事能力；最终仍以完整桌赛、同牌山、换座位、H/M 分层、置信区间、1 秒/3 秒时限和官方测试赛事为准。
4. 若 AV1-3 未见验证失败，关闭该模型版本。只有在失败明确指向缺少信息集平均而非公开状态不可预测时，才进入多隐藏世界教师；否则回到多父代结构搜索，不扩大无证据预算。

## 7. AV1-0/1 实际进展

AV1-0 已完成版本化玩家可见编码。它编码本人手牌、相对座位牌河和副露、公开事件、当前积分和阶段事实、具体吃碰动作、全部合法后继弃牌分支及规则条件路线；场次、赛事、决策、参与者和来源根身份不进入特征。绝对座位旋转、未知/零值分离、非法或非吃碰动作拒绝已经通过契约测试。

AV1-1 使用两个新 `panel_seed`，四个 `seed×H/M` 分片分别在 63、56、62、62 个来源根中顺序取得 32 个机械有效机会，共 128 行、512 张续打桌赛，吃 82、碰 46，零机械无效。辅助阶段积分差为正 50、零 40、负 38，均值 `+3.71875`；主晋级下界差为正 10、零 106、负 12。训练池通过来源和覆盖门槛，但该均值不是候选效果证据。

证据：[`claim-value-dataset-01-20260921`](evidence/r10-supervised-evolution/claim-value-dataset-01-20260921/)。

## 8. AV1-2 失败与复盘

AV1-2 预登记三档线性岭回归与五档深度不超过 3 的回归树，按完整 `panel_seed` 做两折留出；模型不读取 H/M 标签。8 个模型全部未通过。最好整体读数来自岭回归 `λ=1`：辅助策略均值 `+0.929688`、主晋级下界均值 `0`、平衡准确率 `0.473077`；H 为 `+6.90625`，M 为 `-5.046875`。所有模型的 M 辅助读数均为负。

对照的总鸣牌在 H 为 `+11.765625`、M 为 `-4.328125`，主晋级下界总体为 `-0.015625`。H 是三家冻结 V2；M 是 V2、V2 白板保护版和 V1 各一家。H/M 是评估对手池，不是线上可直接读取的事实，禁止把对手池名称加入学生特征。结果表明单轨迹教师存在明显域差异，不能通过泄漏对手标签解决。

证据：[`claim-value-model-01-20260921`](evidence/r10-supervised-evolution/claim-value-model-01-20260921/)。

## 9. 文献触发后的未来顺序方差审计

按 Suphx 的多轨迹奖励估计思路与 rollout 的信息集边界，新增模拟器所有的离线研究接口：只重排当前局尚未摸取的可摸区，保留已消费前缀、四家当前暗手、公开状态、牌张多重集和固定保留区；同一键可复现，当前玩家观察逐字不变。它估计的是给定当前真实隐藏分配时的未来顺序条件方差，不是假称完整后验。

方差审计从 AV1-1 每个 `seed×H/M` 分片按根序取前 4 个有效快照，共 16 个；每个快照执行 8 个冻结未来顺序的过牌/具体鸣牌配对，共 128 个 rollout、512 张桌赛。全部机械有效。结果为：

| 读数 | 结果 |
| --- | ---: |
| 同一快照内同时出现正负非零辅助标签 | 11/16 |
| 快照内辅助标签标准差中位数 | 11.8897 分 |
| 8 次均值后的 H 辅助差 | +4.46875 |
| 8 次均值后的 M 辅助差 | +3.28125 |
| 8 次均值后的 H/M 主晋级下界差 | +0.015625 / 0 |

因此单轨迹标签被未来摸牌顺序显著污染；当前证据支持建立**多未来顺序平均教师**，不支持直接实现吃碰候选。下一训练批必须使用全新面板来源，每个公开快照按同一冻结组的 8 个未来顺序求标签均值，再按来源快照分组训练。上述 16 个快照永不进入新训练或冻结验证。

证据：[`claim-value-future-order-01-20260921`](evidence/r10-supervised-evolution/claim-value-future-order-01-20260921/)。

## 10. 目标切换

单轨迹 AV1 动作价值目标到此终止。后续以 [`R10-AVERAGED-TEACHER-EVOLUTION-PLAN-2026-09-21.md`](R10-AVERAGED-TEACHER-EVOLUTION-PLAN-2026-09-21.md) 为唯一执行计划，目标改为多未来牌序平均教师闭环。既有 128 个 AV1 样本和 16 个方差审计快照只保留为失败与设计证据，不进入新训练、模型选择或独立验证。

AV2 平均教师随后完成，但 8 个低容量模型均未通过整面板留出；该吃碰动作价值路线已经按其停止条件关闭。后续目标和执行门改由 [`R11-DISCARD-ACTION-VALUE-EVOLUTION-PLAN-2026-09-21.md`](R11-DISCARD-ACTION-VALUE-EVOLUTION-PLAN-2026-09-21.md) 管理，本报告不再作为活动计划。
