# R18 P86-02：立即胡与继续追爆头的开发教师预登记（2026-09-25）

## 裁定与边界

**只开放 P85 冻结的 16 个开发状态，评估“立即胡 − R18 v2 原弃非财神”在目标局和当前完整桌的配对差；16 个自然复验状态不解析、不捕获、不模拟。** P85 已在真正 R18 v2 自然轨迹上完成 512/512 张完整桌、62 个独立暴露根，结果盲选取 H/M 各 8 个开发根和各 8 个复验根。[P85 暴露结果](R18-P85-HU-DEFERRAL-NATURAL-EXPOSURE-RESULT-2026-09-25.md)与[风险机制设计](R18-P85-RISK-REPRESENTATION-AND-TEACHER-DESIGN-2026-09-25.md)是本实验的上游。教师源为 [`r18_p86_hu_deferral_development_teacher_v2.py`](evidence/r10-supervised-evolution/r18_p86_hu_deferral_development_teacher_v2.py)。本文和执行源在任何精确前缀预检或收益续打前，由 `prepare` 一起锁入清单。

**本 `-02` 批次替代 `-01` 作为正式教师。** `-01` 只保留历史前缀机械证据；复核发现其第二桌已完成积分按逻辑参与者顺序装入快照，而快照宣称当前物理座位顺序；其续跑/分析又只信任 `mechanical_ok`，没有重新核对配对文件的目标、未来墙和动作身份。新批次修正两处，旧批次不得打开收益或混用文件。

官方指南 v34（本仓 2026-09-15 抓取）确认杭麻只能自摸、摸牌可弃胡，爆头是听牌态摸任意一张即胡，弃非财神会断飘／杠链；v35（2026-09-23 更新）仅澄清 `404 TOURNAMENT_GONE`，未修改上述规则。[官方 v34 正文](../../doc/references/official-guide-v34-content.txt)、[v35 版本](../../doc/references/official-guide-version-v35.json)。这些事实允许比较“现在胡”与“继续”，但**不保证继续者下一次先于对手摸牌或胡牌**。他家暗牌和未来墙只用于离线教师，不进入可发布策略输入。

## 输入身份与机械门

P86 只逐行解析 P85 `dataset.json` 前 16 个 `development` 记录；文件整体哈希仅用于身份锁定，程序不解析第 17—32 个 `replication` 记录。目标文件也只保存 16 个开发记录。每个开发状态最多对应一个 H/M×牌山根，四焦点座位与 32 个未来墙都不增加独立样本数。

每个开发目标以原 `panel_seed=2026102503`、H/M 组合、根、焦点座、桌号重建自然计划。精确重放从桌首到目标窗，必须同时核对：`WindowKey`、玩家观察与规则投影摘要、原 `CompetitionContext` 全字段、生产 `ActionValuePolicy.choose` 的首选弃牌、弃牌和立即 `hu` 均合法、规则即时胡番数及四座 `score_delta`。身份或前缀有一项不一致即停止收益执行。当前完整桌只用原自然桌已完成的阶段排名账重建上下文，不把两桌阶段称为当前桌。

第二桌的 `stage_ledger.completed_table_scores` 按 `stage_plan.participant_ids_by_seat = plan.seats()` 的**物理座位 0—3**写入；不能按 `plan.logical_participants` 顺序写入。断点续跑和分析在读取每个旧配对文件时，都重新核对 `target_id`、未来墙序号和键、两臂冻结/实际动作、强制次数、实际桌数、目标局与即时胡规则结算及积分差；单独的 `mechanical_ok=true` 不构成证据。`-02` 清单显式绑定独立 worktree 的绝对路径，不能把该清单搬到 `main` 后以旧路径验证新运行；跨路径需要重新冻结批次。

只有在源、预算、样本键和下列门全部 `prepare` 冻结后，允许用 `r18-p86-development-01` 做**一次无收益精确前缀预检**：仅保存前缀步数与机械核对结论，不重排未来墙、不强制双臂、不续打、不保存隐藏世界、不读结算差。预检编号 `p86-02-engineering-prefix-preflight-01` 不属于正式未来墙 1—32。

## 配对续打、统计单位与预算

每状态固定自然前缀中的四家暗手；对尚未摸取的可摸牌墙用同一个预先登记的样本键重排，两臂共享该未来墙。参考臂强制一次 R18 v2 原弃牌，干预臂强制一次合法立即 `hu`，其后四座恢复同一冻结策略和 H/M 对手池。两臂各续完**当前完整桌**，共 16 根 × 32 墙 × 2 臂＝**1,024 张完整桌续打**；前 16 墙用于开发选择，后 16 墙只用于同一根的顺序敏感性复查。分叉后牌墙消耗位置可不同，不宣称每步摸牌仍相同；固定隐藏手只代表原自然世界，不代表所有相同公开观察的隐藏世界分布。

每对记录原弃牌、立即胡的实际动作与强制次数、合法性、目标局“本人先胡／他家先胡／流局”、番数、四座结算向量、本人目标局净分、本人当前桌终分、下一局庄位及异常。定义 `Δround = 本人目标局净分_立即胡 − 本人目标局净分_R18`、`Δtable = 本人当前桌终分_立即胡 − 本人当前桌终分_R18`；正值表示立即胡相对原父代有利。立即胡目标局的四座结算必须与冻结合法候选的规则结算一致。每根先平均未来墙，再对 16 个来源根等权汇总；根级 bootstrap 20,000 次，固定随机种子 `2026092586`。预检预算 1 次前缀、正式捕获 16 次前缀；收益预算至多 1,024 张当前完整桌，模型调用 0 次，复验根 0 次。

## 冻结选择与停止门

**这是一项开发机制门，不是可发布策略门。** 前 16 墙若某根 `Δround` 和 `Δtable` 的均值都严格 >0，标记为“立即胡有利”；否则保持 R18 原弃牌。后 16 墙只检验该已固定标记，不再选阈值。只有下列条件全部成立，才允许继续设计一个仅用公开事实的风险边界：

1. 16/16 个精确前缀、512/512 对未来墙、1,024/1,024 张当前完整桌机械核对全通过，零复验读取或执行。
2. 前半墙选出的“立即胡有利”至少 4 个独立根，且 H/M 均至少一个；另至少一个开发根在局级或桌级前半均值严格 <0，构成继续有利或不宜收胡的明确反例。
3. 已选根中至少 75% 的后半墙局级和桌级均值同时严格 >0；将未选根视为保持父代、差值记 0 后，16 根等权的后半局级策略均值 >0。
4. 同一后半墙“开发选择策略”桌级根均值的 bootstrap 95% 下界 >0，留一根最小桌级均值 >0，H/M 各自桌级点均值 >0。

前半结果选出的状态是**教师知道标签的 oracle 选择**，不能部署。即使上述门全绿，也只开放下一步低自由度风险边界设计；必须使用依法可见的即时胡确定价值 `G0`、继续路线 `U/B`、公开时序 `T`、完备性 `K`，与只用 `G0/U/B` 的容量基线同根同墙比较。公开判据及缺失回退先冻结，再打开 P85 的 16 个自然复验根一次，要求桌级根均值 95% 下界 >0、H/M 各点均值 >0，且相对容量基线的桌级根均值增量 >0。后半墙不是独立根盲验；若本教师门失败，保持 R18 v2 并关闭这批状态上的弃胡改进轴，不对已开收益补阈值。

通过复验仍不能直接发布：新牌山同墙换座的**完整两桌阶段**、牌效等胡参照、真实自由赛强对手外部核对、动作时限及官方测试赛事可靠性均另有门。[四臂计划](../r18-four-arm-evaluation-2026-09-23/PLAN.md)、[续接指南](../../doc/evolution-agent-handoff-2026-09-25.md)。
