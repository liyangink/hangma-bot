# G58A 派生情境牌效策略的全程完整桌小批预登记

日期：2026-09-27。**本实验只判断 G58A 值不值得扩大开发，不授予线上、自由赛或独立确认资格。**作者 A 卡原答在严格 JSON 后多出 543 个非空白字符，文本合同失败；[提取器](./g58a_extract_program.py)仅把已可解析的 JSON 前缀中 `def choose(ctx, options)` 原样另存为[派生源码](./g58a_author_program.py)，不把原调用改写成合格。研究[包装器](./g58a_contextual_width_policy.py)先取得冻结 R18 v2 合法保底计划，再于正常本人摸牌、无合法立即胡、父代首选弃牌、无触发专项覆盖时允许纯函数重排合法弃牌，异常或未知事实逐点回退父代。

[91 房结果盲行为诊断](./evidence/g58-executable-search-wave-20260927/official_behavior_diagnostic.json)中，A 原程序在 54,823 个可重判动作窗改选 166 次，触达 139/909 张官方父代完整桌；改选与 G10/G11/G49 同窗同动作分别为 9/28/0，父代已成立爆头资格损失 0，白板实持变化 0，父代评分优势 0–4。[typed 逐窗对账](./evidence/g58-executable-search-wave-20260927/g58a_typed_equivalence.json)已证包装器在这 54,823 窗与原程序完全一致，选择器实测 p95 约 0.067 毫秒、最大约 2.494 毫秒；这不是完整线上动作尾延迟。它的主要作用是早期、他家无公开副露、同综合向听下让较大当前有效牌容量克服少量父代风险／牌河／风格分，不是白板专用算法。即使旧父代轨迹中只影响 139 桌，要全部 909 桌增加 2 分/桌，也需受影响桌均约 `2×909÷139≈13.08` 分；真实候选轨迹会改变触发率，此数不是收益预测或上界。

小批固定 `panel_seed=2026122801`、H/M 两个对手池各 **4 个全新牌山根**、每根四座换位、每阶段 **2 张完整桌**、双臂同种子：共 64 组配对／128 张臂别完整桌。父代 `r18_v2`，候选为本页源码摘要绑定的 G58A typed 包装。逐阶段可恢复，先核全 128 桌完整结算、身份、合法动作、候选实际改选、异常回退和逐单局收支；再按每独立根先平均四座与两桌，报告 H/M 及合并净积分、普通胡／特殊胡收入、非胡付分、末位和描述区间。运行器对需要区分的主目标只使用**完整桌净分**。

机械故障、非法改选、未解释的异常回退或两池均明确下行，关闭该源码并保留证据；不在这批根改公式、改墙段 40 或 `2×容量差`。若无机械问题、两池未同时下行且实际改选足以解释差异，只允许以**完全相同源码**在另一全新面板做 H/M 各 12 根扩样；小批点估计正数本身不算成功。扩样不足 +2 分/全部桌、两池反号或普通胡收入无解释地损失，就关闭；开发过门后另冻结独立确认根与多重选择记账。确认标准仍为相对 R18 v2 ≥+2 分/完整桌、根级配对 95% 区间下界 >0、H/M 同号，再过规则、1/3 秒时限、协议和官方测试房／测试赛事门，正式发布由人审核。R18 v2 继续在线和自由赛运行。
