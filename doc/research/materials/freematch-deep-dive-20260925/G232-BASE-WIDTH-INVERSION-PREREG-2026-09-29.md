# G232：普通父代窗口中的宽进张评分反转普查

日期：2026-09-29。**目的：核查大牌榜第 16 名的“基础牌效已偏向更宽进张，却被熟牌／领先风格反转”是否在未按赢家筛选的父代完整桌中普遍存在，并判断它是否已经被失败的 G193 早期宽面候选覆盖。**本项只读行动前事实，不据父代后续赛果挑窗口，不产生新候选或收益估计。

来源固定为 G224 对 G223 同牌山原样复跑的 64 个阶段、128 张八单局完整桌、2,191 个根弃牌窗口；H/M 各 8 个独立牌山根、四座换位、每阶段两桌。逐阶段文件必须与 G224 `result.json.stage_sha256` 对账。每个根窗口由保存的 `PlayerObservation` 重建生产合法动作与冻结 R18 v2 评分；父代首选、逐备选原评分差、普通型向听、逐码容量必须逐项与 G224 一致，否则整批拒绝。

每个窗口只比较同普通型向听、同白板数的非白合法弃牌。**严格宽面**指相对父代首选，正公开容量的普通有效牌码种数、总公开未见容量同时增加；容量是依法可见的物理上界，不是牌墙概率。为不把七对或已有爆头损失伪装成宽面收益，另标记七对向听不退、综合向听及综合容量不退、原风险单位不升、爆头状态不退。每窗如有多个备选，先报告全部合格数，再按“码数较多、容量较大、原分差较小、动作键”确定一张代表牌，防止把一窗当多次独立命中。

**基础牌效反转**严格定义为：代表备选 `base_score` 大于父代、冻结 R18 总分不高于父代；在两动作总分中同时删除 `river_part` 与 `style_part` 后，备选反超父代。所有分量差与总分差必须守恒；不把 `other` 或风险差归给熟牌。报告全部原始窗口、每完整桌首次命中，以及按 H/M、白板数、普通型向听分层的窗口数、涉及桌数、涉及独立根数。重复窗口与同根四座不冒充独立证据。

另以 G193 冻结源码的已知行动前门槛，标记反转窗是否落在“未副露、三向听、零至一白、白板高番状态未激活、宽度和容量门、近端路线／风险门、原分差 0–4”的受试域；不调用 G193 已看桌赛结果反向选门槛。若反转主要落在 G193 域，其完整桌失败已是直接反证，关闭“减熟牌／风格奖即可修复”的单机制。若主要在域外，列明具体遗漏层，但只在新根构造普通胡与高番竞争终点及对手截尾后才考虑候选。

本批不做显著性或发布判断。任何下一代候选仍须独有行为、全新 H/M 同牌山换座完整桌净分与独立确认、规则／时限／官方接线门；榜单赢家和本批父代后续均不充当反事实标签。
