# G160：跨行动价值教师的新 H/M 父代表来源预登记

日期：2026-09-28。**目的不是再证明「进张更宽」，而是给候选作者建立新的、行动前选样且能做同世界续打的冲突来源。**G157/G159 已否证一步全保白静态宽度在相应入口的独有性；G67/G68 的两摸与 G43 的三摸理想化容量没有给稳定桌分。下阶段必须分开普通型到达、七对/白板机会、他家先胡截尾与完整桌净分。本批先产生冻结 R18 v2 的完整父代表与观察，不运行备选收益，也不产生新线上候选。

## 冻结来源和切分

- 使用冻结 R18 v2 评分源码、现有 H/M 异质对手池及生产 `HangmaRules`。新 `panel_seed=2026111901`，牌山根 1–24，每根 H/M 各四座换位、每阶段一张完整八单局桌，合计 **192 张完整父代表**；与 G81、G114、G118、G126–G130 牌山种子不同。
- 完全复用 [G126 采集器](./g126_all_draw_natural_width_exposure.py)的规则谓词：每个官方单局只保存首个父代合法非白弃牌与另一合法非白弃牌，其普通型向听相同，备选普通型有效牌码种数和生产公开未见容量都严格更宽；同时保留父代完整评分及各分量，核父代实际执行动作。这个母体仅是研究冲突，不把宽度当优选标签。
- 未来教师主层在**打开任何续打结果前**固定为：本人尚无吃/碰、普通型弃后二向听、行动前持 0 或 1 张白板。每 `对手池×牌山根×白板格` 最多选一窗，按 `(observation_sha256, focal_seat, round_no)` 字典序，不读历史结算或未来牌墙。根 1–16 为开发，17–24 为机制锁定；本轮只统计两层触达，锁定层不运行备选分支。
- 未来同世界教师只强制首个合法弃牌，然后冻结四方策略续打；开发根每窗至少 32 个观察一致隐藏世界并保留原始历史世界作回归。按窗口、根和 H/M 分开记录普通一番自摸、二番以上自摸、七对/爆头、他家先胡、本人再次行动及单局积分；同窗多世界与同根多窗均不可冒充独立桌。若样本或运行成本不足，先报告覆盖，不用少量极端窗口调新阈值。

## 后续候选门

开发教师只能帮助建立**动作前可算**、与 G11/G49/G81/G88/G131/G150 行为不同的普通速度×白板兑现×对手竞速交互；不能把赛后隐藏世界、实际摸牌或胜负标签送进线上 `PlayerObservation`。任何公式须先冻结并经机制锁定根筛查，之后另用完全新 H/M 同牌山四座完整桌作策略开发及独立确认：相对冻结 R18 v2 合并至少 +2 分／桌、牌山根级 95% 下界 >0、两池同号，并通过规则、1/3 秒时限和官方接线门。自由赛观察仍只用于外部复盘。
