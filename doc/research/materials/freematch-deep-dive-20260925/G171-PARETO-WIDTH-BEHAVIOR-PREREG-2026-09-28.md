# G171：普通宽面与综合／七对／公开风险联合保护的结果盲行为门

日期：2026-09-28。**G168 证明严格拓宽普通进张可改善下一摸牌形，却在完整桌亏分；G169/G170 发现它常同时削弱七对或综合牌效，并覆盖父代的公开风险偏好。**G171 是一个新的、有界的行动前假设：在 G168 相同的首次零白、无本人吃碰、普通型二向听目标窗，只从生产合法非白弃牌中选普通有效牌码数与公开未见容量**同时严格增加**的备选；还要求综合向听不退、综合有效张公开容量不减、七对向听不退、冻结 R18 v2 的公开副露邻近风险单位不增。先在同一观察里筛出所有满足保护的备选，再按普通牌码数、容量、动作键确定选择。若存在严格宽面冲突却无可接受备选，本手消耗一次机会并保持父代；不在后续摸打重试。

公开未见容量只是物理上界，不作摸牌概率；七对或综合事实未知时保守回退。风险单位只读取同次冻结 R18 v2 评分轨迹的行动前 `risk_units`，不是未来是否被鸣的真值。本版**仍允许**用更宽普通进张覆盖父代熟牌／领先风格奖励，检验去掉显式路线退化与副露邻近加险后，是否存在可兑现的宽面价值；不宣称熟牌奖励错误。候选先返回完整合法排序，保留原保底、拒绝过滤和父代其他动作。

行为门只重建 [G166 已固定的 64 个行动前观察](./G166-FRESH-ROOT-EXPOSURE-RESULT-2026-09-28.md)和 [G168 已看完整桌](./G168-ZEROWHITE-FIRST-WIDTH-DEVELOPMENT-RESULT-2026-09-28.md)的合法改选身份，不读取其积分。须核 0 次非法动作、0 次一白/响应窗越位、两池均有与 G11/G30/G88 不同的改弃、改弃行动前各保护逐项成立，才能启动**全新牌山根**开发桌赛。行为旧样本仅作可执行性与去重检查，不作收益预示。

若新根完整桌仍不能两池同向、合并至少 +2 分／桌且根级 95% 下界 >0，关闭这一版零白静态宽面联合闸，不能用同一结果再调保护项或打分权重。即便开发过门，另需独立新根、规则／时限／状态恢复及官方门。G160 的 25 个机制锁定窗仍封存。
