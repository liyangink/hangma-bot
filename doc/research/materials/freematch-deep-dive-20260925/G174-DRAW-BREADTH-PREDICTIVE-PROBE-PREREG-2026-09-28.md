# G174：进张牌码多样性能否预测下一次本人正常摸牌命中

日期：2026-09-28。**检验自然进张“码数多”是否在已知公开有效张容量之后仍含独立信息。**这不是弃牌候选收益实验，也不把未来牌当线上特征；只分析冻结 R18 v2 官方已接受弃牌后的实际下一次本人正常摸牌。若更多牌码不能预测额外命中，就不能仅凭“对手可能扣住某种牌”给多样性固定奖励；若能预测，也须另在新候选完整桌证明价值。

母体是 G11/G172 同一冻结 91 间房、909 张完整桌、55,170 个已接受正常摸打弃牌。按同一 `game_id/round_no/seat` 的 `trigger_seq` 排序，只取前后两次本人正常摸打之间**副露数相同、前次弃后手牌计数等于后次摸前手牌计数**的机械连续对；其他情形明确计截尾或不匹配，绝不把未到达当未命中。首窗父代动作的生产 `standard_useful_tiles` 中，正公开容量牌码集合是线上可见输入；下一次摸牌码是否在集合内是离线标签。容量为零的牌码不算进张。排除首窗普通型有效张容量为零或事实未知，报告每层样本与删失量。

房号 SHA-256 固定拆分：`sha256("g174-holdout|" + room_id) % 5 == 0` 为完全留出房，其余为训练房；不以窗随机拆分。首窗特征仅用普通型公开容量 `C`、正容量牌码数 `T`、普通型向听、动作前白板数、本人副露数和墙余张数。比较两种固定形式的惩罚逻辑回归：基础式含截距、`C/40`、`(C/40)^2`、`W/80`、`(W/80)^2`、向听 0/1/2/3+、白板 0/1/2+ 和副露数；扩展式只增 `T/10`。优化总负对数似然，除截距外用固定 L2 系数 1，不在留出房调参。报告训练的多样性系数、留出房逐窗对数损失与 Brier 分数；留出房按房间有放回重采样 2,000 次，区间用房间为统计单位。另报零／一／多白分层和命中基率，避免大层掩盖稀有层。

事前解释线：只有多样性系数为正、留出房基础式减扩展式的平均对数损失 **≥0.001 nat/窗** 且房间 bootstrap 95% 下界 >0，才称“在已接受父代行动分布上，多样性对下一摸命中有额外预测价值”。否则不据此增加固定多样性奖金。即使通过，仍只能说明到达下一摸后的条件预测，不证明某备选弃牌会改善赛事净积分、七对与白板高番，也不外推未选动作；需另做动作前候选与新根完整桌。G160 锁定窗不使用。
