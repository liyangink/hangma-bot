# G230：进张牌码多样性能否抵消他家暗手占牌

日期：2026-09-29。**先检验隐藏牌墙的实际可得张数，再决定是否值得把“进张牌码多样性”写入下一代评分。**这是一项赛后机制检验，不是策略收益实验、线上输入或大牌赢家模仿标签。

## 固定来源与比较

目标固定为 [G63 全量普查](./G62-G63-SHARED-HORIZON-RESULT-2026-09-28.md)的 56 个强手／冻结 R18 v2 弃牌对：双方普通型和综合向听同层，强手动作的生产普通型正容量进张牌码更多，公开总容量不增。目标身份、行动前 `PlayerObservation` 和动作来自 G61 已核官方正常摸打窗口；输入原文与脚本 SHA-256 记录在输出。全部 56 窗先入账，不以赛后牌墙或结局筛选。每个强手座位单局的首个目标另作去重口径，同房样本按房聚类。

每窗用当前生产规则重新核两种弃牌合法性与普通型逐牌有效张；再用同一生产普通型缺口求解器，白板不当百搭，得到双方“无白自然进张”。自然比较仅在缺口相同、强手牌码更多且公开容量不增时定义主层；不满足者留在全部样本中并注明原因。选择、容量与进张计算只读行动前依法可见状态。

## 赛后打开的标签与计算

按官方 `start_hands` 和完整事件重建**当前摸牌之后、弃牌之前**四家暗手、公开牌河与副露；用每种牌四张的守恒式得到当时真实牌墙逐码张数。逐码核 `0 ≤ 真实墙张数 ≤ 公开未知容量`，总墙数等于行动前观察的墙余；任何不成立的窗口记错误、不得猜墙。真实墙牌码只用于本离线标签，禁止投影到候选或在线观察。

对任一动作的进张集合 `S`，公开容量 `C(S)=Σc_t`，真实墙库存 `A(S)=Σw_t`。公开未知池 `U=当前墙余 W + 他家暗手张数`。若未知牌在墙与他家暗手间可交换，条件基准为 `E[A(S)]=W×C(S)/U`；这是**比较基准的假设**，不是麻将对手实际行为概率。每对报告强手减父代的 `ΔA`、`ΔE` 与剩余差 `ΔA−ΔE`，分别按生产普通型去白和无白自然进张计算。容量相等子层单列。另列 `ΔA>0` 的比例、强手／房覆盖、按座位单局首窗去重结果以及按官方房聚类的确定性重采样区间。不得把墙库存当下一次本人摸牌、胡牌或整桌收益。

若无白自然主层在玄武与腾蛇两侧均呈正的房级剩余差、且去重与容量相等子层不反向，才考虑从**公开事实**设计容量修正代理，仍须在新来源校准和未见 H/M 完整桌验证。否则关闭“固定奖励更多牌码以抵御他家占牌”这张独立作者卡；保留进张路线与白板高番联合价值主线。无论本项结果如何，冻结 R18 v2 都是唯一线上父代。
