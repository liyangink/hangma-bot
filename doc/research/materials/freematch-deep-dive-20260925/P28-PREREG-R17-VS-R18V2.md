# P28 预登记：**R17 的 2 步公开后继搜索，相对 R18 v2 有没有增量**

登记人：主审。实验 ID：**P28-R17-VS-R18V2**。状态：**已登记，已派**。
类型：**开发机制门**（不是可发布策略门）。

## 一、问题（既往从未被问过）

项目里已有一套**通过生产准入**的 2 步公开后继搜索（R17）：
规则侧 `analyze_public_self_draw_successors`、固定归约器 `reduce_public_successors`、
叶程序执行器、以及两个冻结候选 A/B。它的生产准入实测
**p99 = 186–199 ms、最大单窗 201 ms**（1 秒动作窗内可行）。

**但它的评价基线自始至终是 `ComparableHeuristicPolicyV2`（稳定 V2），
而当前部署的是 `r18_integrated_positive_v2`。**

- R17 的策略类**没有注册进任何策略表**，也**没有接线进 R18**；
- 主审逐行读过 R18 v2 源码（825 行）：它只消费
  `actions[].routes` / `useful_tiles` / `baotou_after` / `value_coverage`，
  **完全没有使用后继分析**。

**⇒「R17 相对 R18 v2 的增量」从未被测量。**

## 二、为什么这是本会话最值得重开的一条

本会话刚用三条测量关闭了「层内排序」：`C10` **−33.81**、`C11` **−8.27**、`C15` **−1.99**（CI 含 0）。
**但那三次用的都是任意/无信息的规则。R17-B 是同一层的「有信息版本」**
（用 2 步公开后继的真实容量与后继叶事实来排序弃牌）。
**它就是「信息能不能救回排序」这个问题的一个已经造好、已经准入、成本可接受的答案。**

## 四、判定（**先写死**）

必须同时报三组数（缺一不可）：

1. **总体保守 U 差**（`candidate.u_low − baseline.u_high` 的单元均值）；
2. **阶段积分差均值**（分/桌口径的诊断量）；
3. **第四率差**（候选 vs 基线）。

| 条件 | 判定 |
| --- | --- |
| 总体保守 U 差 > 0 **且** 阶段积分差均值 > 0 **且** 正效应跨 ≥2 个根与 ≥2 个座位 | 允许进入下一级（另一来源复现 / 更大样本确认） |
| 保守 U 差 > 0 但阶段积分差 ≤ 0（或反之，符号相反） | **不给结论**，报实测值交回主审 |
| 两者都 ≤ 0 | **关闭「2 步公开后继搜索」这条轴**（在当前 R18 v2 父代之上无增量），并明确写出「这是本会话最后一条未测的信息通道」 |

**必须在报告里单独写一句**：这批的符号是**相对 R18 v2**的，
不是相对稳定 V2 的；R17 原批次（相对稳定 V2 为正）与本批**不冲突**。

## 五、必须报的口径与自检

1. **逐单元核对基线策略身份**：确认每张桌的基线确实是 `r18_integrated_positive_v2`，
   抽样打印 `policy_id`；
2. **R17 归约失败 / 响应窗精确回退的计数**（原批次要求「合格摸牌归约失败 0、响应窗非精确回退 0」）；
3. **改序计数**：候选把 R18 v2 的弃牌顺序改了多少个窗口（这是可达性的真实读数）；
4. **成本**：每个决策的规则侧耗时（p50/p99/max），与 1 秒窗比对；
5. **「这次测量可能怎么错」**：逐条列失效模式与检验结果。

## 六、边界

- R17「只能重排弃牌」，不能改变胡/杠/过/吃碰选择；
- 保守 U 是**效用区间**口径，与「分/桌」不同名，**不得直接换算**；
- 阶段积分差是**诊断量**，原 R17 报告明确说它不替代 U 门；
- 若判定为关闭，应当把它与本会话已有的三条层内排序测量并列记录：
  `C10` −33.81 / `C11` −8.27 / `C15` −1.99 / **R17 2 步（本批）**。
