# G93：同世界、同单局合法弃牌双分支量具预检

日期：2026-09-28。**此步只验证离线量具能合法复现与分叉，不以一张牌的结果生成候选或推断收益。**G90–G92 已证明 G88 的 M 池失分大多在首个结果分歧后的单局积累；需要先分开“本次弃牌所在单局的动作价值”和整桌跨局传导，最终晋级仍只看新根完整桌。

先在 G89 已冻结 H 池根 1、焦点座位 0 的第一张桌运行冻结 R18 v2。只由 `DecisionRequest` 中的本人公开吃碰、合法弃牌、普通型向听与有效牌事实，确定首个“父代首选为弃牌，且存在同普通型向听的合法备选弃牌”的摸牌窗口；若不存在则在同一根后续焦点座位依序找，不看结算挑窗。研究包装器只保存此窗口的不可变模拟世界引用，评估策略从未读它。用已存在的 `resume_match` 从同一世界分别续打：(A) 父代原首选，(B) 仅在该窗口一次性改为预定备选，后续全部恢复父代；在本单局结算后由模拟器公开 `export_hand` 给分数与番型，研究包装器把它表示为单局终点，不修改生产规则或驱动。

通过条件：完整未分叉桌的最终积分与 G89 存档逐座位相同；分叉起点官方可见观察摘要相同；A 的该单局结算与完整桌对应局逐字段相同；B 确实只替换目标窗口一次，动作由生产 `HangmaRules` 合法表给出，后续无强制干预；两支无非法动作、超时或保底降级，单局积分守恒。记录目标窗口键、两动作的普通型进张码数/公开容量及本单局结算；不保存隐藏手牌或整面牌墙。若恒等对照失败，不开放大样本分支研究，更不召回 LLM 生成基于错误量具的评分。
