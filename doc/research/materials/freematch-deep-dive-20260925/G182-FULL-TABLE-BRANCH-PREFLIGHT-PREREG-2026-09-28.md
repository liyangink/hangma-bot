# G182：同一行动前世界强制一次弃牌后续打完整桌的机械预检

日期：2026-09-28。**用途：在投入竞争终点教师与蒸馏训练前，先证明现有 `resume_match` 可以从同一冻结父代动作窗口续打至整张桌赛终点，且不改弃分支与原父代表逐局恒等。** G93/G161 已验证目标单局续打，不能据此自动声称完整桌可续。

来源固定为 G160 结果盲选样的开发层，按 `(root_index, focal_seat, round_no)` 排序，分别取 H/零白与 M/一白最前的一个窗口；选样不读后续积分。各窗重放冻结 R18 v2 父代表，核 `observation_sha256`、父代和严格宽面备选动作。对历史隐藏世界及预先固定的 `g182-01`、`g182-02` 两个公开观察一致重采样世界，各做父代/仅第一次强制备选两个分支；其后四座全用原冻结策略。训练标签与特征均不产生，在线策略不改。

完整桌续打只复用 `SimulationEngine`、`HandAccountingEngine` 和 `resume_match` 的公开接口，不复制规则或写入 `WorldState`。在历史世界，父代分支须对原父代表从目标单局起的每一局结算与最终四座分数完全相同；双臂须起点观察、初始分数相同，备选恰好强制一次合法弃牌，随后完成原赛制规定的八个单局，零非法/超时/保底，逐局积分守恒并有完整桌最终分数。重采样只需双臂同世界起点一致，不得拿历史父代逐局结算去要求重采样世界恒等。任一条不满足即判 full-table teacher 当前不可用，先修机械续打，不训练模型、不把单局收益冒充桌赛收益。

记录 H/M 各窗、三世界双臂的逐局结算摘要、完整桌本座积分差、分支耗时及源摘要；这些六对样本只是机械预检，不是策略强度证据或训练集。通过后再另行冻结新 H/M 根、多动作/世界抽样、互斥终点分类、训练/留出与上线时限门。
