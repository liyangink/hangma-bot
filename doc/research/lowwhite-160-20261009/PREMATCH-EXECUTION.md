# 赛前单白兑现有限复核

本次有限复核已结束：8个独立160单局开发阶段净积分差全部0，未达到确认门，保留正式P0。候选在1280个本家单局中实际作用4次，只加快已有合法胡后的兑现，没有观察到阶段增收。16个独立确认根未启动，新候选未进入自由赛，也未制作上线包。

候选范围是单白已合法2倍胡、全部合法弃牌后的下一普通摸牌报价均不增收时，及时兑现。它是旧PlateauHu的有限复核，增加拒绝动作与降级守卫，不作为全新机制绕过旧停止记录。

用户已授权持续推进，CPU核心最多使用80%。机器物理／逻辑核心均14，工作进程上限为11，降低运行优先级，一次只开一个计算池。赛前冻结期限为2026年10月10日16点（北京时间）。

## 机制与公开行为

13个旧延胡窗口的实际远目标（`option`，兑现比较真正消费的保白目标）均为标准型、保留一白、自然缺张0、额外行动负担0。它们均依靠完成信用胜过当前胡，继续信用去除此项后不再胜过当前胡。排序点不是期望积分；这仍不证明整个远期没有新白、飘或杠的升级机会。

34份公开输入经真实规则分析与 `choose` 检查，旧13窗实际改胡，其余21份保持完整父计划。另检查已拒绝胡、胡从父计划移除、预算不足、当前飘、杠补、父计划降级与额外投影失败，均保持原计划。单次检查最大策略耗时约0.169秒；这不替代10场并发的动作时限验收。

6个不同旧单局各取首个目标窗，仅将子臂该窗改为胡，之后双方都使用P0，完整续到原第16局。父代终分全部精确复现。条件净差为57、88、0、35、0、0分，合计180分；其中目标单局结算差合计76分，后续单局差104分，高番收入条件差合计40分。它们来自4个旧来源、5份原桌赛，含同桌不同单局的相关尾段，是固定窗口教师标签，不是自然160单局阶段的收益估计。没有根据后续赢输挑选窗口，也不能再叠加固定庄权奖分。

## 冻结预算与门禁

阶段（`Stage`，此处本家十桌各十六单局共160单局）是收益验证的抽样单位。每根包含父子各两次循环换座，共40份完整R16桌赛实例；循环换座相互关联，不增加独立样本数。对手为三个冻结P0实验参照，不冒称真实排行榜强手。

| 项目 | 事前标准 |
| --- | --- |
| 开发 | 固定8个新独立根，全数计入；均值净差大于0，至少2根为正，去掉最大正根后均值仍大于0 |
| 独立确认 | 开发通过后固定16个独立根，不按结果补根；平均每160单局至少增加10分，按阶段根重采样的95%置信区间下端大于0 |
| 能力保护 | 当前多白、高番、真升级和其他非作用输入保持父计划；全阶段高番收入差的95%区间下端不低于−20分／160单局，并继续审阅多白机会、庄闲支付及尾部 |
| 运行与发布 | 规则／合法动作、动作时限、10场资源、包绑定与生命周期回归；通过后提交具体包供人审核，并按已授权范围安排自由赛验证 |
| 到期或失败 | 16点停止新版本变动；没有达到门禁就保留P0，不能将条件正标签替代独立确认 |

高番区间门槛仅是这次有限投资的可检验保护线，不证明所有大牌能力等效。庄付闲、闲付庄、闲付闲分开对账；胡牌保庄、实际胡牌抢庄及后续净积分分别报告。累计获得白牌的阶段分层会随策略结束时点改变，只描述分布，不冒充固定条件下的因果收益。

## 完整结果与处置

320份完整R16桌赛实例全部自然完成。父子牌山、循环换座轨迹、四座积分守恒及逐手结算对账通过，非法动作、超时、降级和辅助失败均0。这里使用逻辑预算；不能将这些计数当作新候选10场在线原截止验收。

另做10个预热进程同步的公开决策检查，6份目标首窗加4份其他公开输入，使用生产 `BudgetPolicy` 的原1秒／3秒预算，计入规则分析和策略调用。10份均合法、无降级、在原保底与最晚发送截止前完成，规则分析与策略总耗时最大约0.110秒。这是生产核心的并发窗口检查；HTTP提交、恢复和真实赛事生命周期未在本候选上执行，不授线上准入。

4个实际作用窗的公开观察摘要经复原核对，实际远目标仍均为标准型、保留一白、自然缺张0、额外负担0；本人均为闲家。它们分别少等3、2、2、1个本人摸牌决策窗，但最终赢家、倍数和支付均相同。此前单次教师的正标签在这组新自然阶段上没有转化为积分增量；不能用教师合计180分替代自然收益。

按8个开发根整体重采样，净差与高番收入差的95%区间均为[0,0]。这是八个零观测的组内重采样结果，不能证明总体收益严格为0，也不能排除其他对手池中的稀有正负效果。开发门要求净差均值大于0且至少两根为正，本批未满足；独立确认、候选线上包和自由赛验证按门禁不启动。未调整种子、候选或预算以追正结果。

11个低优先级工作进程在36.29分钟完成自然批次。实测单池11个计算子进程，抽样CPU占用约全机78.1%，工作进程内存约935 MiB。按本批实例工作时间折算，两进程理想时间约195分钟；这是工作量折算，未进行额外两进程实测。

现行正式P0的 `approved-v5` 包已通过当前主线校验器，启动准入有效；源码与研究父代一致。没有改动正式策略、参赛配置或运行源码。此次不把“收益门未通过”写成上线验收通过。原先PlateauHu首组0活动、0净差保留，旧竞争兑现+37分单根和此次教师标签不进入新独立确认。
